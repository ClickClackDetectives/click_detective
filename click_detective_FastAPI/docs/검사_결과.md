## 나머지 검사 범위

인증·수사 소유권·자산·영상 Range·자료 열람·복원·정확한 출처 조합·쟁점·단계 전환·UUID 중복·revision 충돌·종결 후 거절을 검사합니다. 초기 상태의 고발, 추론 0개/1개 고발, 미확보 추론 거절도 확인합니다.

LangGraph 테스트는 실제 세 노드를 실행하되 모델 출력과 의미 판정은 모의 모델로 제공합니다. 원문과 다른 대사 통과·생성/검증의 목적별 디코딩·수량 변조 거절·오류 후 승인 원문 복구도 포함합니다.

## 실제 GPU 결과와 구분

이번 pytest는 fixture·모의 모델 기반이며 실제 GPU를 추가로 로딩하거나 새 학습하지 않았습니다. 기존 실서버 보고서는 그대로 보존했습니다. v6의 130개 실제 질문 결과와 v7의 코드 회귀 결과를 같은 실행으로 합치지 않습니다.

실제 모델의 새 표현 다양성과 의미 판정 품질은 서버를 재시작한 뒤 [실서버 검사](11_LLM_멀티에이전트_실서버_테스트.md)로 별도 확인해야 합니다. pytest 통과만으로 실제 Qwen·양자화·어댑터·VRAM·생성 품질을 입증하지 않습니다.
