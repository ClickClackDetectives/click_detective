# 수사 진행과 고발 조건

증거 열람과 심문으로 자료를 모으고, 확보한 자료를 조합해 추론합니다. FastAPI는 조사 단계 전환과 최종 고발을 판정합니다. 아래 공략에는 사건 정답이 포함되어 있습니다.

## 읽을 문서

- 자료 열람부터 심문, 추론, 단계 전환까지 순서대로 따라갑니다. [진행 예제](진행_예제.md)
- 추가 이미지의 경로, 열람 조건, 기존 수사의 동작을 확인합니다. [2차 증거 이미지](2차_증거_이미지.md)
- 모든 자료·쟁점·추론을 모으는 공략을 확인합니다. [진행도 100%](진행도_100퍼센트.md)
- 고발에 필요한 조건과 점수 계산을 확인합니다. [최소 통과 조건](최소_통과_조건.md)
