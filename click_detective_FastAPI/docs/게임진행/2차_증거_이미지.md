# 2차 조사 증거 이미지

2차 조사 원본 증거 `2-01`부터 `2-11`까지 참고 이미지가 있습니다. 파일은 `data/public/assets/evidence/2-01.png` 형식으로 보관합니다. 새 그림은 imagegen으로 만든 참고 일러스트이며, 정확한 단서·수치·진술은 자료 본문을 기준으로 확인합니다.

## 기존 수사 기록을 유지하는 방식

원본 `data/case/evidence.json`과 `data/manifest.json`을 수정하지 않았으므로 사건 버전이 바뀌지 않습니다. 기존 수사를 초기화하거나 DB를 삭제하지 않아도 됩니다. 추가 이미지의 파일 목록과 체크섬은 `data/generated-evidence-assets.json`에 보관하며, 이 목록은 사건 버전 계산에 포함하지 않습니다.

## 서버 처리 순서

1. 자료 상세·이미지 API가 수사 소유권과 열람 권한을 검사합니다.
2. `evidence_image_path`가 원본 `illustration` 경로를 확인합니다.
3. 원본 경로가 비어 있으면 `assets/evidence/{증거ID}.png`에서 추가 이미지를 찾습니다.
4. 파일이 `data/public` 내부에 실제로 있는 경우에만 상세 응답에 보호된 이미지 API 주소를 넣습니다.
5. 이미지가 없으면 상세 응답의 `illustration`은 `null`, 이미지 API는 404입니다.

Next.js는 받은 주소를 `/api/detective/evidence-assets/{증거ID}`로 바꾸어 팝업에 표시합니다. 이미지를 새로 받지 못한 자료의 예전 주소는 제거합니다. 이미지는 공개 자산 경로에서 제공하지 않으므로 2차 조사 전이나 열람 전에는 볼 수 없습니다.

## 수정 후 화면에 반영하기

FastAPI와 Next.js를 재시작한 뒤 브라우저를 새로고침하고 기존 수사를 이어가세요. Next.js를 배포용으로 실행한다면 `npm run build` 후 다시 실행합니다. 수사 기록 초기화는 필요하지 않습니다.
