# 수사 진행도 100% 달성 조건

[문서 목차](../README.md) · [최소 통과 조건](최소_통과_조건.md)

이 문서는 현재 FastAPI 규칙과 사건 JSON을 기준으로 작성했습니다. 사건의 쟁점과 추론 조합이 포함됩니다. 원본 share_project의 예전 고발 제한과 혼동하지 마세요.

## 정확한 계산식

원본 자료 29개 + 발견 쟁점 10개 + 생성한 추론 10개 = **49개**입니다.

`percent = min(100, floor(완료 개수 / 49 × 100 + 0.5))`

모든 항목은 중복 없이 한 번만 셉니다. 48/49는 98%이며 49/49에서 100%입니다. 증언 개수·심문 횟수·메모·선택한 범인·고발 점수는 진행도 항목이 아닙니다. 자료 목록에 제목이 보이거나 GET으로 목록을 조회한 것만으로 열람이 증가하지 않습니다.

## 2. 발견 쟁점 10개

다음 조건의 원본 근거를 **해당 인물에게 제시**해야 합니다. 단순 열람과 제시는 다릅니다. 한 심문에는 자료 한 개를 첨부하지만 같은 인물의 과거 제시는 누적됩니다. 여러 원본을 포함한 실제 추론을 제시하면 그 추론의 최종 원본 근거도 사용합니다.

| 쟁점 | 인물 | 필요한 원본 근거 |
| --- | --- | --- |
| 와인잔의 약 (`gang_drug`) | 강민호 | 1-08 + 1-02 |
| 밤 11시의 재방문 (`gang_visit`) | 강민호 | 1-13 |
| 자문료의 행방 (`yoon_money`) | 윤재혁 | S-Y |
| 금고를 연 사람 (`yoon_visit`) | 윤재혁 | 2-01 + S-Y |
| 초안을 가져온 밤 (`sera_draft`) | 백세라 | S-B + 1-07 |
| 사진 속 아이 (`cha_identity`) | 차도윤 | S-C + 1-11 |
| 세 점의 위작 (`seo_forgery`) | 서하은 | 1-10 + 2-02 |
| 벽난로에 남은 것 (`seo_burn`) | 서하은 | 2-04 + 2-07 + 2-11 |
| 받침과 뒤통수 손상의 부합 (`weapon_fit`) | 서하은 | 1-03 + 2-03 |
| 소각 시간대 목격의 한계 (`witness_gap`) | 차도윤 | 2-04 + 2-11 |

쟁점은 승인 계획을 반영한 대화가 정상 확정될 때 저장됩니다. stop뿐 아니라 기본 정책의 fallback·fixture도 승인된 쟁점을 저장할 수 있습니다. 조건이 없는 질문을 많이 했다고 새 쟁점이 생기지는 않습니다.

## 3. 추론 10개 생성

`POST /v1/games/{game_id}/inferences`에 출처 2~4개를 전달합니다. **조합은 정확히 일치**해야 합니다. 불필요한 자료를 하나 더 넣거나, 선행 추론 대신 그 원본을 선택하면 다른 조합입니다. 진술은 실제 심문으로 기록된 ID를 선택합니다.

| 코드 | 결론 | 생성 단계 | 정확한 출처 |
| --- | --- | --- | --- |
| IF-101 | 개입 지점은 와인병보다 개별 잔 | 1차 | 1-02（원본） + kang-admit-gang_drug（획득 진술） |
| IF-102 | 채무 공개를 미루고 원본을 회수할 유인 | 1차 | 1-13（원본） + S-K（원본） + 1-08（원본） |
| IF-103 | 미서명 초안은 상속 확정이 아니다 | 1차 | S-B（원본） + cha-admit-cha_identity（획득 진술） |
| IF-201 | 뒤통수 손상과 부엉이 받침의 적합성 | 2차 | 1-01（원본） + 1-03（원본） + 2-03（원본） |
| IF-202 | 22:35–22:45 거실에는 관찰 공백이 있다 | 2차 | cha-absence（획득 진술） + baek-white-glove（획득 진술） + cha-fireplace（획득 진술） |
| IF-203 | 자정 예고는 위작 은폐를 압박했다 | 2차 | 1-10（원본） + 2-02（원본） + 2-08（원본） |
| IF-204 | 장갑 한 켤레와 소각 현장의 물품 연결 | 2차 | 2-04（원본） + 2-07（원본） + S-S（원본） + 2-11（원본） |
| IF-205 | 저택 시계만으로 행적을 확정할 수 없다 | 2차 | 1-06（원본） + 2-05（원본） |
| IF-301 | 수면제 투약과 치명적 가격은 별개 행위 | 2차 | IF-201（추론） + 1-08（원본） + kang-admit-gang_drug（획득 진술） |
| IF-302 | 소각은 폭로 기록을 없애려는 후속 은폐 | 2차 | IF-203（추론） + 2-04（원본） + seo-admit-seo_burn（획득 진술） |

추론의 내부 ID는 `derived-` + 규칙 id입니다. 예를 들어 IF-201은 `derived-reset-impact-fit`입니다. 같은 추론을 반복 생성해도 개수가 늘지 않습니다.

## 권장 진행 순서

1. 1차 자료를 열람하고 강민호·윤재혁·백세라·차도윤의 1차 쟁점을 확보합니다.
2. **IF-101·IF-102·IF-103을 모두 1차에서 생성**합니다. 2차에 들어간 뒤 1차 추론을 새로 만들려고 하면 단계 불일치로 거절됩니다.
3. 추론 2개·쟁점 2개 이상이라는 2차 진입 조건을 충족한 상태에서 조사 단계를 전환합니다.
4. 2차 자료를 전부 열람합니다. 차도윤과 백세라의 동선 질문으로 IF-202에 필요한 진술을 확보합니다.
5. IF-201~205를 생성하고, 필요한 자료나 이 추론을 해당 인물에게 제시해 남은 쟁점을 확보합니다.
6. IF-201과 투약 인정으로 IF-301, IF-203과 소각 인정으로 IF-302를 만듭니다.
7. 응답 state.progress에서 counts가 evidence=29, findings=10, inference=10이고 percent=100인지 확인합니다.
8. **고발은 수사를 종결하므로 100%를 목표로 한다면 수집을 마친 뒤 제출합니다.**

질문 한도는 전체 25회입니다. 자기소개나 무관한 질문도 정상 확정되면 1회를 소비합니다. 모든 자유 질문이 자동으로 필요한 진술을 선택하지 않으므로 동선은 화면의 동선 주제 버튼을 사용하는 편이 분명합니다.

## 100%와 100점의 차이

100%는 수집 완료, 100점은 범인·동기·수단·핵심 근거 네 채점 항목의 성공입니다. 둘은 독립적입니다. 100%라도 오답이면 고발 점수가 낮고, 100%가 아니어도 핵심을 입증하면 정답 100점이 가능합니다.
