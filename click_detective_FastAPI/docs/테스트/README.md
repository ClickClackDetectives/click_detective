# 테스트 문서

[전체 목차](../README.md)

Ruff와 pytest로 코드 규칙과 회귀 동작을 확인한다. 계정·수사 통합은 임시 DB를 사용하고, 모델 생성 품질은 local 실서버에서 별도로 검사한다.

| 문서 | 확인할 내용 |
|---|---|
| [자동 검사와 문제 해결](자동검사와_문제해결.md) | pytest·Ruff·진단 이벤트·오류 확인 |
| [실서버 LLM 검사](실서버_LLM_검사.md) | 실행 중인 local 서버에 실제 심문 요청 보내기 |
| [최근 검사 결과](최근_검사_결과.md) | 마지막으로 확인한 결과와 검사 범위 |
| [테스트 코드 참조](../코드참조/README.md#회귀-테스트) | 현재 테스트 파일별 선언문과 설명 |

기본 자동 검사는 fixture·모의 모델을 사용한다. 게임 API·LangGraph 연결·재시도·저장 규칙을 검사하지만 실제 Qwen 품질이나 GPU 양자화 실행을 입증하지 않는다.
