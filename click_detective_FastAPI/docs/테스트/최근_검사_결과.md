테스트 실행에서는 langsmith 내부의 `asyncio.iscoroutinefunction` 사용 중단 예고 13개도 관찰되었다. 검사 실패와 구분한다.

## 검사 범위

인증·수사 권한·생성 중복·자산·자료 열람·게임 완료·고발·저장 복원·revision 충돌·생성 중 상태 변경을 검사한다. 실제 LangGraph 노드를 연결하되 모델 출력과 의미 보고서는 모의 모델로 제공한다.

최근 추가·보강한 범위는 다음과 같다.

- 검증 보고서의 JSON·스키마·항목·근거 오류만 같은 후보로 재요청
- 보고서 형식 실패 상한 소진 시 대사 재생성을 하지 않는 정책
- 의미상 거절은 새 대사 생성으로 연결되는 정책
- 검증 배치 분리 후에도 원래 승인 문맥 유지
- 필수 사실 보존, 동점 선택 순서, 검색 결과 깊은 복사, 검색 비활성화
- 파일당 250줄 제한과 docstring 설명

[테스트 파일별 설명](../코드참조/README.md#회귀-테스트)

## 실제 모델과의 구분

이 검사로 실제 Qwen·호환 어댑터·GPU 로딩·NF4 실행·VRAM·의미 판정 품질을 확인한 것은 아니다. 과거 실서버 보고서도 이번 코드의 새로운 GPU 결과와 합치지 않는다.

실제 모델은 서버를 준비한 뒤 [실서버 검사](실서버_LLM_검사.md)에서 별도로 확인한다. `fallback`을 사용자에게 제공한 성공과 모델의 `stop` 생성 성공을 구분해서 기록한다.
