## 제거한 항목

- `.pytest_cache`
- `app/__pycache__`
- `app/api`
- `app/dialogue/__pycache__`
- `app/dialogue/rag/__pycache__`

- `tests/__pycache__`

app/api는 import하는 실행 코드 없이 빈 초기화 파일만 있던 준비 패키지였습니다. 경로 등록은 app/main.py에서 이루어집니다. integrations/nextjs는 빈 준비 폴더였고 실제 연결 코드는 형제 프로젝트 click_detective_nextjs에 있습니다. __pycache__와 .pytest_cache는 실행/검사 때 다시 생기는 캐시입니다. 테스트 후 재생성된 캐시도 마지막에 정리했습니다.

- 업무 API 개수를 18개로 통일하고 화면 조회 API를 목록에 포함했습니다.
- Next.js 미연결 설명을 현재 click_detective_nextjs BFF 연결 구조로 수정했습니다.
- 없어진 준비 폴더와 오래된 폴더 트리를 수정했습니다.
- 1차·증거 0개 고발, 선택적 추론 제출, 입증 채점과 제출 자격의 차이를 설명했습니다.

- 실제 API 함수의 소스 줄 링크와 입력 스키마를 점검했습니다.
- 파일별 문서를 현재 AST에서 다시 구성해 오래된 시그니처·분기·코드 발췌를 교체했습니다. 새 테스트·130개 실행 도구 등 누락된 Python 파일도 포함했습니다.
- 100% 조건과 최소 통과 조건을 별도 문서로 작성하고 현재 API로 간소 경로를 검증했습니다.
