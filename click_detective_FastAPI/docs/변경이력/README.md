# 변경 이력

[전체 목차](../README.md)

## 2026-11-18 호환 경로 정리

- 저장소에서 사용하지 않는 호환 모듈 18개를 제거하고 코드 참조와 Colab의 파일 생성 셀을 정리했다.

## 2026-11-16 문서 재구성

- 시작 안내·에이전트·서버·API·테스트·게임 진행·코드 참조로 문서를 분류했다.
- 전처리·생성·검증 에이전트를 각각의 폴더와 실제 클래스 선언문으로 설명했다.
- 분리 전의 긴 함수 본문을 복제한 문서를 현재 소스의 선언문·docstring 참조로 교체했다.
- Python 파일 118개에 대한 코드 참조를 작성하고 호환용 import 파일을 구분했다.
- API 18개 경로의 실제 처리 함수와 현재 소스 위치를 연결했다.
- 이전 문서 경로를 사용하던 프로젝트·프런트엔드 문서의 링크도 갱신했다.

이전 루트의 01~14 안내 문서는 현재 목차의 주제별 문서로 이동했다. `API_상세`는 `API/상세`, `파이썬_파일별_상세`는 `코드참조`로 바뀌었다.
