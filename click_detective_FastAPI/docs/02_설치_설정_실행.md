# 02. 설치·설정·실행

[목차](README.md) · [기본 안내](01_프로젝트_기본안내서.md)

## 1. 가상환경

이 프로젝트에서 사용할 환경은 `.cd_venv`입니다. 가상환경은 프로젝트별 Python 패키지를 분리하는 폴더입니다.

```bash
cd ~/reverse/click_detective
source .cd_venv/bin/activate
python -m pip install -e '.[dev]'
```

환경을 새로 만들 때만 `python3 -m venv .cd_venv`를 실행합니다. Python 3.11 이상이 필요합니다. 설치한 환경은 다음으로 확인합니다.

```bash
python -c "import sys; print(sys.executable)"
python -m pip check
```

실제 모델용 패키지는 별도입니다.

```bash
python -m pip install -e '.[local]'
```

GPU·드라이버·PyTorch·bitsandbytes의 호환 환경이 필요합니다. 기본·테스트 패키지를 설치했다고 GPU 모델 준비가 끝난 것은 아닙니다.

## 2. .env를 읽는 방법

Settings가 click_detective/.env를 읽고, 서버 시작의 lifespan에서 Settings()를 만듭니다. 설정 우선순위는 코드 직접 지정 → 프로세스 환경변수 → .env → 코드 기본값입니다. .env를 바꾼 후 서버를 재시작해야 합니다.

이미 생성된 .env에는 실제 서비스 키가 있으므로 예제 파일을 덮어 복사하지 마세요. 없는 환경에서만 .env.example을 복사하고 키를 바꿉니다. 문서에는 실제 키를 적지 않습니다.

상대 경로는 실행 위치가 아니라 click_detective 기준입니다. `~`는 사용자 홈으로 확장합니다.

## 3. 기본 설정

| 환경변수                       | 의미·기본값                                                               |
| ------------------------------ | ------------------------------------------------------------------------- |
| CLICK_API_KEY                  | 최소 16자 서비스 비밀 키. 필수                                            |
| CLICK_GENERATION_MODE          | local 또는 fixture. 기본 local                                            |
| CLICK_DATA_DIR                 | ./data                                                                    |
| CLICK_DATABASE_PATH            | ./.data/games.sqlite3                                                     |
| CLICK_LOCAL_MODEL_PATH         | ./models/Qwen2.5-7B-Instruct                                              |
| CLICK_LOCAL_MODEL_VERSION      | Qwen2.5-7B-Instruct-nf4                                                   |
| CLICK_LORA_ADAPTER_PATH        | ./adapters/best_adapter                                                   |
| CLICK_ADAPTER_VERSION          | provided-adapter. 실제 어댑터 버전으로 변경 권장                          |
| CLICK_GENERATION_OUTPUT_FORMAT | text 또는 json. 기본 text                                                 |
| CLICK_MAX_INPUT_TOKENS         | 2048. 허용 128~8192                                                       |
| CLICK_MAX_NEW_TOKENS           | 512. 허용 32~2048                                                         |
| CLICK_DIALOGUE_TEMPERATURE | 생성 자유도 0.65. 0이면 greedy, 검증은 항상 greedy |
| CLICK_DIALOGUE_TOP_P | 생성 후보 누적 확률 0.9 |
| CLICK_DIALOGUE_REPETITION_PENALTY | 생성 토큰 반복 억제 1.05 |
| CLICK_TIMEOUT_SECONDS          | 90초. 0보다 크고 180 이하                                                 |
| CLICK_GENERATION_ATTEMPTS      | 최초 포함 생성 총 시도 수 2. 1~3                                          |
| CLICK_VERIFICATION_ATTEMPTS    | 묶음별 형식 검증 총 시도 수 2. 1~3                                        |
| CLICK_VERIFICATION_BATCH_SIZE  | 문장 검증 묶음 크기 10. 1~10                                              |
| CLICK_FALLBACK_ON_ERROR        | 기본 true. 생성·검증 실패 시 승인 원문으로 복구; false는 별도 strict 검사 |
| CLICK_RAG_ENABLED              | 기본 true                                                                 |
| CLICK_RAG_TOP_K                | 선택 사실 최대 3개. 0~10, 필수 사실은 별도 보존                           |
| CLICK_HISTORY_LIMIT            | 최근 이력 6개. 0~20                                                       |
| CLICK_DIAGNOSTICS_ENABLED      | 기본 true                                                                 |
| CLICK_DIAGNOSTICS_PATH         | ./.data/dialogue-traces.jsonl                                             |

역할이 다른 api_key와 모델 토큰 예산의 token을 혼동하지 마세요. max_input_tokens를 낮추면 긴 입력을 자동 요약하는 것이 아니라 초과 요청을 거절합니다. max_new_tokens가 너무 작으면 검증 JSON이 끝나기 전에 잘릴 수 있습니다.

## 4. 모델과 어댑터 복사

```text
models/Qwen2.5-7B-Instruct/
  config.json
  tokenizer_config.json
  tokenizer.json 등 토크나이저 파일
  model.safetensors.index.json + 가중치 조각들
adapters/best_adapter/
  adapter_config.json
  adapter_model.safetensors
```

가중치는 모델에 따라 단일 safetensors 또는 지원되는 PyTorch 가중치 파일일 수도 있습니다. 어댑터 가중치는 safetensors 또는 bin을 허용합니다. 서버는 로컬 파일만 읽으며 자동 다운로드·학습하지 않습니다. 어댑터 폴더가 없으면 조용히 생략하지 않고 시작 오류를 냅니다. 모델과 어댑터가 서로 호환되어야 합니다.

## 5. 실행

```bash
cd ~/reverse/click_detective
source .cd_venv/bin/activate
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --workers 1
```

local은 시작 시 모델을 로딩하므로 시간이 걸릴 수 있습니다. `http://127.0.0.1:8000/healthz`와 `/docs`에서 확인합니다. /healthz는 생성 품질 검사를 수행하지 않습니다.

GPU 없이 API를 확인하려면 .env의 CLICK_GENERATION_MODE=fixture로 바꾸고 재시작합니다. API·게임 규칙은 실행되지만 대사는 실제 모델 생성이 아닙니다.

현재는 모델 공유·추론 잠금·간단한 SQLite 운영을 고려해 worker 1개로 시작하세요. 다중 프로세스·다중 GPU 운영은 별도 검증이 필요합니다.

## 6. 자주 막히는 지점

- 설정 필수값 오류: CLICK_API_KEY와 .env 위치 확인.
- Missing local model file / weights: 모델 경로와 실제 파일 확인.
- LoRA adapter ... missing: 어댑터 경로·설정·가중치 확인.
- CUDA GPU 오류: local 패키지·GPU 환경 확인. fixture와 실제 모델을 구분.
- 포트 사용 중: 다른 서버를 확인하거나 포트를 변경하고 호출 주소도 맞춤.
- 모델을 바꿨는데 같은 응답: 완료된 같은 request_id를 재전송했는지 확인.

## 플레이용 복구 설정 적용

`CLICK_FALLBACK_ON_ERROR=true`는 승인 사실 범위의 fallback을 허용합니다. 설정을 바꾼 뒤 FastAPI를 재시작하세요. stop은 실제 모델 성공, fixed는 fixture/중립 답변, fallback은 생성 실패 후 원문 복구입니다. 질문 한도·종결·인증·revision 조건은 유지합니다. [상세 정책](12_질문_응답과_복구_정책.md)


## 대사 재서술과 표현 자유도

생성은 temperature 0.65·top_p 0.9의 샘플링, 검증은 greedy로 분리합니다. 원문 표현 대신 사실의 의미를 보존합니다. 설정·재시작·진단은 [RAG 사실 보존과 자유로운 대사 생성](13_RAG_사실보존과_자유로운_대사생성.md)에서 확인하세요.

현재 모델이 프로젝트 최상위 `Qwen2.5-7B-Instruct/`에 있다면 `.env`의 CLICK_LOCAL_MODEL_PATH를 그 실제 위치로 지정합니다. models/ 안내는 기본 예시 경로이며, 이 정리에서는 가중치나 어댑터를 이동하지 않았습니다.
