# 원본 Next.js 화면용 조회 API

`GET /v1/games/{game_id}/views/{screen}`은 원본 share_project 화면을 유지하기 위한 표시 전용 API입니다. 서비스 Bearer와 X-Game-Token이 모두 필요합니다. 조회는 수사 revision을 변경하지 않습니다.

| screen | 검색 조건 | 출력 |
|---|---|---|
| evidence | search, place | available·places·groups·readCount |
| testimonies | search, person | 증언자별 visible: 최초 진술·집사 문서·획득 진술·질문/답변 쌍 |
| inference | search, category | 실제 획득 출처 중 visible |

screen은 evidence·testimonies·inference만 허용합니다. 다른 값은 404입니다. 검색은 원본처럼 앞뒤 공백을 제거하고 소문자 비교합니다. body는 이 응답에 공개하지 않습니다. 본문은 기존 획득 권한을 확인하는 materials/{material_key}로 읽습니다.

추가로 catalog.display는 본문 없는 원본 자료 메타데이터·화면 목표 개수만 제공합니다. state.ui는 실제 획득한 필수 추론 ID, 근거 분류 이름, 자료실 집계를 제공합니다. 정답 설명 checkDetails는 수사 종결 후 verdict에서만 공개합니다.
