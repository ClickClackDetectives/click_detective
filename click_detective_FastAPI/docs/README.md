## 중요한 범위

FastAPI 게임 API와 자체 데이터 처리는 구현되어 있습니다. 실제 모델 실행에는 사용자가 복사한 가중치·호환 어댑터·GPU 환경이 필요합니다. 새 click_detective_nextjs는 원본 UI를 유지하며 이 백엔드에 연결합니다. 원본 share_project 자체는 변경하지 않습니다. 문서는 현재 코드와 확인한 검사 결과를 설명하며 실제 모델 품질이나 완료되지 않은 화면 연동을 완료로 표현하지 않습니다.

추가 API: [원본 화면 조회](API_상세/18_원본화면_조회.md).

## 현재 질문 응답 정책

쟁점과 무관하게 유효한 질문에 답변을 준비하며, 모델 실패 시 승인 원문으로 복구합니다. [질문 응답·복구·쟁점 저장 정책](12_질문_응답과_복구_정책.md)에서 stop·fixed·fallback, 질문 차감과 strict 검사를 함께 확인하세요.


## 대사 재서술과 표현 자유도

생성은 temperature 0.65·top_p 0.9의 샘플링, 검증은 greedy로 분리합니다. 원문 표현 대신 사실의 의미를 보존합니다. 설정·재시작·진단은 [RAG 사실 보존과 자유로운 대사 생성](13_RAG_사실보존과_자유로운_대사생성.md)에서 확인하세요.
