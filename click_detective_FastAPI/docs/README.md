## 문서와 코드가 연결되는 방식

설명에서 함수는 다음처럼 실제 선언문으로 보여준다. `...`는 본문을 생략했다는 뜻이다.

```python
async def preprocess_agent(self, state: InterrogationState) -> dict:
    ...
```

각 단계의 설명 아래에서 역할과 처리 순서를 읽고, 필요한 경우 소스 링크로 실제 구현을 확인한다. 예전 import를 위한 짧은 연결 파일과 실제 구현 파일은 [코드 참조](코드참조/README.md)에서 구분한다.

모든 프로젝트 Python 파일은 docstring을 포함해 250줄 이내로 관리한다. 문서는 실제 구현과 검사 범위를 설명하며, fixture·모의 모델 검사를 실제 GPU 생성 품질 검증으로 취급하지 않는다.
