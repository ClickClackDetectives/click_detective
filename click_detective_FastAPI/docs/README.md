# FastAPI 개발·운영 문서

처음 서버를 띄울 때는 시작 안내를 따르고, 실행 중인 서버를 확인할 때는 API와 운영 문서를 사용합니다.

## 읽을 문서

- 설치부터 앱의 요청 처리 흐름까지 따라갑니다. [시작하기](시작하기/README.md)
- 인증 헤더와 요청 형식, 응답 오류를 확인합니다. [API 안내](API/README.md)
- MongoDB, PostgreSQL, 화면 서버를 연결합니다. [서버 운영](서버/README.md)
- 심문에서 승인된 사실이 대사와 기록으로 이어지는 과정을 읽습니다. [대화 에이전트](에이전트/README.md)
- 정적 검사, DB fixture, 실제 모델 검사를 실행합니다. [검사 안내](테스트/README.md)
- 자료 수집과 고발 조건을 살펴봅니다. 공략에는 정답이 있습니다. [게임 진행](게임진행/README.md)
- 업무별 Python 파일과 선언 위치를 찾습니다. [코드 참조](코드참조/README.md)
- 구조 이관과 검색 기능 도입 기록을 확인합니다. [변경 이력](변경이력/README.md)
