# FastAPI를 처음 실행하는 순서

서버를 시작한 뒤 카탈로그 조회와 새 수사 생성을 확인하면 사건 데이터에서 저장소까지의 흐름을 한 번 따라갈 수 있습니다.

## 읽을 문서

- 게임 서버와 화면 서버의 역할을 확인합니다. [프로젝트 소개](01_프로젝트_소개.md)
- Python과 MongoDB를 준비하고 fixture로 서버를 띄웁니다. [설치와 실행](02_설치와_실행.md)
- 카탈로그 조회, 수사 생성, 복원, 심문을 호출합니다. [첫 API 호출](../API/처음_호출하기.md)
- 앱 시작과 조회·변경 요청을 추적합니다. [전체 처리 흐름](03_전체_처리_흐름.md)
- 런타임과 네 도메인의 진입점을 찾습니다. [코드 읽는 순서](04_코드_읽는_순서.md)
- 계정 로그인과 저장된 수사 연결이 필요할 때 PostgreSQL을 설정합니다. [계정과 수사 저장소](05_계정과_수사_저장소.md)
