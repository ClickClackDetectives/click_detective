# 계정과 수사 저장소

SQLAlchemy ORM은 PostgreSQL의 이메일·Argon2id 비밀번호 해시와 로그인 세션을 관리합니다. MongoEngine ODM은 MongoDB replica set의 수사 상태, 소유권과 요청 UUID로 재생할 응답을 관리합니다. 익명 수사와 계정 수사에 같은 MongoDB 연결을 사용합니다.

## 연결

1. 수사 저장에는 MongoDB replica set이 필요합니다. 계정 기능을 사용할 환경에는 PostgreSQL도 준비합니다. [MongoDB 설치와 실행](../서버/MongoDB_설치와_실행.md) · [PostgreSQL 설치와 실행](../서버/PostgreSQL_설치와_실행.md)
2. FastAPI 환경에 `CLICK_POSTGRES_DSN`, `CLICK_MONGO_URI`, `CLICK_MONGO_DATABASE`, `CLICK_AUTH_JWT_SECRET`을 설정합니다. 서명 키는 `openssl rand -hex 32`로 따로 생성합니다. 설정 예시는 [환경변수 예시](../../.env.example)를 참고합니다.
3. FastAPI를 시작하면 테이블, 컬렉션과 인덱스를 준비합니다. Next.js에는 기존 FastAPI URL과 서비스 키만 설정합니다. 개발 환경에서 모델 없이 인증·수사를 검증하려면 FastAPI에 `CLICK_GENERATION_MODE=fixture`를 설정합니다.

이 작업공간의 FastAPI `.env`에 사용자 설치의 DB 연결 설정을 저장했다면, FastAPI 디렉터리에서 바로 서버를 시작할 수 있습니다. 서버가 내려가 있으면 각 DB 문서의 사용자 설치 실행 절차를 따릅니다.

```sh
CLICK_GENERATION_MODE=fixture .click_venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

## API

| 경로 | 추가 인증과 동작 |
| --- | --- |
| `POST /auth/signup` | 이메일과 8~16자 비밀번호를 검사하고 공개 계정을 반환합니다. 비밀번호에는 영문 대소문자 중 하나, 숫자와 `!`, `@`, `#` 같은 ASCII 특수문자가 각각 하나 이상 필요합니다. |
| `POST /auth/login` | 공개 계정, 접근·갱신 토큰과 만료 시각을 서버에 반환합니다. Next.js는 토큰을 HttpOnly 쿠키에 설정합니다. |
| `GET /auth/me` | `X-Access-Token`으로 활성 세션을 조회합니다. |
| `POST /auth/refresh` | `X-Refresh-Token`을 회전합니다. 로그인부터 7일 뒤 세션이 종료됩니다. |
| `POST /auth/logout` | 갱신 또는 접근 토큰으로 세션을 폐기합니다. |
| `POST /auth/delete` | 활성 세션과 현재 비밀번호로 삭제 작업을 등록하고 계정의 세션을 폐기합니다. |
| `GET /v1/investigations` | 계정 소유 목록을 `items`와 `next_cursor`로 반환합니다. |
| `POST /v1/investigations/claim` | 계정 접근 토큰과 `X-Game-Token`으로 본문의 `game_id`를 계정에 연결합니다. |
| 기존 `/v1/games` 하위 경로 | 계정 접근 헤더가 있으면 계정 소유권을 확인합니다. 계정으로 생성할 때 `game_token`은 null입니다. |

서비스 키 검증 실패는 `SERVICE_AUTH_REQUIRED`입니다. 인증 만료는 `ACCESS_TOKEN_EXPIRED`, 세션 폐기는 `SESSION_REVOKED`입니다. `X-Expected-User-Id`가 실제 세션과 다르면 `ACCOUNT_CHANGED`로 처리해 이전 계정의 대기 요청이 새 계정에 적용되지 않게 합니다.

가입과 로그인에는 이메일 및 FastAPI가 신뢰하는 접속 주소 기준의 PostgreSQL 횟수 제한을 적용합니다. Next.js 중계가 사용자 주소를 전달하지 않는 배포에서는 같은 중계 인스턴스의 요청이 주소 한도를 공유합니다. 운영 환경에서는 신뢰할 수 있는 프록시 경계와 입구의 요청 제한을 배포 구성에 맞춰 설정합니다.

## 계정 삭제 작업

삭제 요청은 계정 접근을 차단하고 이미 시작한 요청이 끝날 수 있도록 15분 뒤 정리 가능 상태가 됩니다. FastAPI와 같은 DB 환경에서 `python -m scripts.process_account_deletions`를 운영 작업으로 주기적으로 실행합니다. 작업은 MongoDB의 해당 계정 수사와 요청 기록을 삭제한 뒤 PostgreSQL의 계정과 세션을 정리합니다. 실행에 실패한 작업은 다음 처리 시각 이후 다시 실행할 수 있습니다.

## 검증

`CLICK_TEST_POSTGRES_DSN`과 `CLICK_TEST_MONGO_URI`를 준비한 뒤 `python -m pytest -q`를 실행합니다. 통합 테스트는 임시 스키마와 임시 MongoDB DB를 만들고 정리합니다. FastAPI의 수사 fixture는 MongoDB 연결을 사용합니다.
