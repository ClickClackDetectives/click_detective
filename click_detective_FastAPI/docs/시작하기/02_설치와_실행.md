# 설치와 실행

[전체 목차](../README.md) · 이전: [프로젝트 소개](01_프로젝트_소개.md) · 다음: [전체 처리 흐름](03_전체_처리_흐름.md)

## 1. 가상환경과 의존성

Python 3.11 이상을 준비하고 두 프로젝트의 상위 폴더에서 시작한다. 아래 가상환경 이름은 `.click_venv`다. 이미 사용하는 환경이 있으면 그 환경을 활성화한다.

```bash
cd click_detective_FastAPI
python3 -m venv .click_venv
source .click_venv/bin/activate
python -m pip install -e '.[dev]'
```

`dev`에는 테스트와 코드·포맷 검사 도구가 포함된다. 활성화한 환경은 다음으로 확인한다.

```bash
python -c "import sys; print(sys.executable)"
python -m pip check
```

## 2. GPU 없이 먼저 실행하기

`.env`가 없을 때 예제 파일을 복사한다. 기존 파일이 있으면 필요한 항목만 수정한다.

```bash
cp -n .env.example .env
```

`.env`에 16자 이상의 서비스 키와 수사를 저장할 MongoDB replica set 연결 문자열을 설정한다. [저장소 설정](05_계정과_수사_저장소.md)

```dotenv
CLICK_API_KEY=replace-with-a-long-random-service-key
CLICK_GENERATION_MODE=fixture
CLICK_MONGO_URI=mongodb://USER:PASSWORD@127.0.0.1:27017/?replicaSet=rs0
```

```bash
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --workers 1
```

- 상태 확인: [healthz](http://127.0.0.1:8000/healthz)
- API 문서: [Swagger](http://127.0.0.1:8000/docs)

`fixture`는 실제 AI 생성 없이 게임 규칙과 저장을 확인하는 모드다. API 인증과 수사별 토큰은 [공통 규칙](../API/공통규칙.md)을 참고한다.

## 3. 실제 모델로 실행하기

호환되는 CUDA GPU·드라이버 환경을 준비하고 같은 가상환경에 모델 의존성을 설치한다.

```bash
python -m pip install -e '.[local]'
```

모델 가중치·토크나이저와 설정된 LoRA 어댑터를 별도로 준비한다. 기본 경로 예시는 다음과 같다.

```text
models/Qwen2.5-7B-Instruct/
  config.json
  tokenizer_config.json
  토크나이저 파일과 모델 가중치
adapters/best_adapter/
  adapter_config.json
  adapter_model.safetensors 또는 adapter_model.bin
```

```dotenv
CLICK_GENERATION_MODE=local
CLICK_LOCAL_MODEL_PATH=./models/Qwen2.5-7B-Instruct
CLICK_LORA_ADAPTER_PATH=./adapters/best_adapter
```

파일이 다른 위치에 있으면 실제 경로를 지정한다. 준비되지 않은 모델·어댑터를 자동으로 받거나, 설정된 어댑터를 조용히 생략하지 않는다. local 서버를 실행할 때는 기존 서버를 종료한 뒤 같은 실행 명령으로 재시작한다.

모델 로딩 과정은 [공용 모델](../에이전트/공용_모델.md)에서 설명한다.

## 4. 설정을 읽는 규칙

[Settings](../../app/config.py)는 프로젝트의 `.env`를 읽는다. 일반 설정 우선순위는 직접 전달한 값 → 프로세스 환경변수 → `.env` → 코드 기본값이다. 상대 경로는 실행한 디렉터리가 아니라 `click_detective_FastAPI`를 기준으로 해석한다. 변경한 설정은 서버 재시작 후 적용된다.

| 환경변수 | 코드 기본값 | 의미 |
|---|---|---|
| `CLICK_API_KEY` | 필수 | 서버 간 인증 키 |
| `CLICK_GENERATION_MODE` | `local` | fixture 또는 실제 모델 |
| `CLICK_MONGO_URI` | 필수 | 수사 저장용 MongoDB replica set 연결 문자열 |
| `CLICK_LOCAL_MODEL_PATH` | `models/Qwen2.5-7B-Instruct` | 모델 파일 위치 |
| `CLICK_LORA_ADAPTER_PATH` | `adapters/best_adapter` | 기존 어댑터 위치 |
| `CLICK_GENERATION_OUTPUT_FORMAT` | `text` | 내부 생성 출력 형식 |
| `CLICK_TIMEOUT_SECONDS` | 90 | 그래프 전체와 처리 단계의 초 단위 제한 |
| `CLICK_GENERATION_ATTEMPTS` | 2 | 최초 포함 대사 생성 상한 |
| `CLICK_VERIFICATION_ATTEMPTS` | 2 | 배치별 보고서 요청 상한 |
| `CLICK_VERIFICATION_BATCH_SIZE` | 10 | 한 번에 검사할 승인 문장 수 |
| `CLICK_FALLBACK_ON_ERROR` | `true` | 실패 시 승인 원문 복구 |
| `CLICK_RAG_ENABLED` / `CLICK_RAG_TOP_K` | `true` / 3 | 자유 질문 E5 검색 / 개별 진술 수 상한 |
| `CLICK_HISTORY_LIMIT` | 6 | 최근 대화 항목 수 |
| `CLICK_MAX_INPUT_TOKENS` / `CLICK_MAX_NEW_TOKENS` | 2048 / 512 | 입력 / 새 출력 토큰 상한 |
| `CLICK_DIALOGUE_TEMPERATURE` / `CLICK_DIALOGUE_TOP_P` | 0.65 / 0.9 | 대사 샘플링 설정 |
| `CLICK_DIALOGUE_REPETITION_PENALTY` | 1.05 | 대사 반복 억제 |
| `CLICK_DIAGNOSTICS_ENABLED` | `true` | 진단 기록 여부 |
| `CLICK_DIAGNOSTICS_PATH` | `.data/dialogue-traces.jsonl` | 진단 파일 |

전체 필드와 허용 범위는 [Settings 코드 참조](../코드참조/app/config.md)에서 확인한다.
