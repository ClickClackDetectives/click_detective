# FastAPI 연결과 호출

먼저 `GET /healthz`로 서버 상태를 확인합니다. 서버 간 요청에 서비스 키를 사용하고, 익명 수사에서는 수사 생성 응답의 게임 토큰을, 계정 수사에서는 계정 액세스 토큰을 함께 전달합니다.

## 읽을 문서

- 헤더, 오류 응답, 상태 변경 요청의 식별자와 버전을 확인합니다. [공통 요청 규칙](공통규칙.md)
- 카탈로그에서 사건을 골라 수사를 만들고 이어서 조회합니다. [첫 호출 실습](처음_호출하기.md)
- 자료 열람, 심문, 추론, 메모, 고발의 요청과 응답을 찾습니다. [엔드포인트 상세](상세/README.md)
- 계정 API와 로그인한 사용자의 수사 연동 경로를 확인합니다. [계정과 수사 연결](../시작하기/05_계정과_수사_저장소.md)
- 내부 `GET/POST /internal/agent-test`의 활성화 및 인증 조건을 확인합니다. [실서버 모델 검사](../테스트/실서버_LLM_검사.md)
