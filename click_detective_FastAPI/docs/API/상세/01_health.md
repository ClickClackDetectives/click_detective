# 01. 서버 시작 완료 확인

`GET /healthz`

앱 시작이 끝났는지 확인한다. 배포 환경의 준비 상태 검사에 사용할 수 있다.

[API 목차](README.md) · [인증·재시도 공통 규칙](../공통규칙.md)

## 접근 조건

인증 없이 호출한다.

## 입력

요청 본문은 없습니다.

## 서버 처리 순서

1. 앱 시작 절차를 마친 서버가 응답 가능한지 확인합니다. fixture에서는 모델을 로딩하지 않습니다.
2. 실제 질문 생성이나 GPU 여유 메모리를 검사하지 않습니다.

## 응답

응답에서 주로 쓰는 필드를 발췌한 예시다.

```json
{
  "status": "ok"
}
```

## 실패·주의점

- 서비스 시작 전에 설정·데이터·모델 로딩에 실패하면 이 응답 자체를 받을 수 없습니다.

처리 진입점은 `health()`이다. [컨트롤러 소스](../../../app/main.py#L106)
