# 01. 프로젝트 기본 안내서

[문서 목차](README.md) · 다음: [설치와 설정](02_설치_설정_실행.md)

## 어떤 프로젝트인가요?

click_detective는 추리 게임의 데이터를 읽고, 수사 상태를 저장하고, 게임 규칙을 판정하며, 캐릭터 대사를 만드는 Python 서버입니다. FastAPI는 HTTP 요청을 Python 함수에 연결하고 결과를 JSON으로 반환합니다.

예를 들어 사용자가 “증거 열람”을 누르면 서버가 현재 조사 단계에서 그 자료를 볼 수 있는지 검사합니다. 허용되면 열람 기록을 저장하고 화면용 상태를 반환합니다. Next.js는 그 결과를 보여 주는 역할을 맡도록 설계했습니다.

## 현재 가능한 일

| 기능                       | 현재 구현                                      |
| -------------------------- | ---------------------------------------------- |
| 사건·인물·초기 화면 데이터 | catalog·cases API                              |
| 이미지·영상                | 공개 자산과 수사 권한 자산 API                 |
| 수사 시작·복원             | SQLite와 게임 토큰                             |
| 자료 열람·본문             | 획득·단계 검사                                 |
| 심문                       | 승인 계획 → 3개 에이전트 → 대화·진술·쟁점 확정 |
| 추론                       | 실제 출처의 정확한 조합 판정                   |
| 조사 단계 전환             | 추론·쟁점 조건과 자동 자료 처리                |
| 메모                       | revision을 검사하는 전체 저장                  |
| 고발                       | 언제든 제출·선택 항목과 근거 채점                  |
| 화면용 가공                | 자료 목록·진행률·타임라인·가능 행동            |

업무 API는 메서드·경로 조합으로 18개입니다. /docs·/redoc·/openapi.json은 문서용 경로입니다.

## 서버와 화면의 경계

게임의 공식 상태는 FastAPI DB가 소유합니다. Next.js가 질문 횟수나 발견한 쟁점을 임의로 증가시켜 저장하지 않습니다. 탭 선택·모달 열기·입력 중 텍스트 같은 임시 UI 상태는 화면에 둘 수 있습니다.

연결된 화면 프로젝트는 `../click_detective_nextjs`입니다. 이 프로젝트의 Next.js BFF가 서비스 키와 수사 토큰을 보관하고 FastAPI 응답을 원본 UI에 표시합니다. 원본 share_project는 보존되어 있습니다. 사용하지 않던 integrations/nextjs 준비 폴더는 제거했습니다.

## 실행 모드 두 가지

| 값      | 대사 처리                    | 필요한 것                              |
| ------- | ---------------------------- | -------------------------------------- |
| local   | 로컬 Qwen 생성·검증          | CUDA GPU·모델·호환 어댑터·local 패키지 |
| fixture | 승인 원문을 연결한 고정 응답 | 기본 API 패키지                        |

기본은 local입니다. fixture는 테스트·개발용이며 Qwen이 실행된 것처럼 표시하지 않습니다. fixture의 응답은 finish_reason=fixed입니다.

local 모드라도 승인 사실이 없으면 그래프에서 모델 호출 없이 중립 응답을 반환할 수 있습니다. 질문을 받았다고 모든 비밀을 모델에 주는 구조는 아닙니다.

## 처음 읽을 용어

| 용어            | 쉬운 의미                                                 |
| --------------- | --------------------------------------------------------- |
| API             | 화면이 서버에 일을 요청하는 약속                          |
| JSON            | 이름과 값으로 데이터를 표현하는 형식                      |
| DTO·Schema      | 허용하는 필드·자료형을 정한 입력/출력 형식                |
| request_id      | 이번 행동의 UUID. 같은 행동 재전송에서는 유지             |
| revision        | 수사 상태가 바뀐 순서를 나타내는 버전                     |
| scenarioVersion | 게임 데이터 패키지의 버전                                 |
| 토큰            | 여기서는 인증 비밀값 또는 LLM 글자 조각. 문맥에 따라 구분 |
| 트랜잭션        | 여러 DB 변경을 함께 확정하거나 함께 취소하는 단위         |
| RAG             | 승인된 사실에서 질문 관련 내용을 고르는 검색              |
| LoRA            | 모델 전체 대신 작은 어댑터를 적용하는 방식                |
| QLoRa           | 양자화 기반 모델 위에서 어댑터를 학습하는 방식            |

이 서버는 학습을 수행하지 않습니다. 제공한 어댑터를 추론에 적용합니다. 양자화된 추론과 QLoRa 학습은 구분해야 합니다.

## 질문에는 답하고 쟁점은 조건에 따라 기록합니다

기본 플레이 설정에서는 모델 실패에도 승인 원문으로 복구해 답변을 반환합니다. 정보가 없는 질문은 중립 답변입니다. 복구 대화도 1회 질문으로 기록하며, 아직 조건이 충족되지 않은 쟁점은 추가하지 않습니다. 자세한 경계는 [응답 정책](12_질문_응답과_복구_정책.md)을 참고하세요.
