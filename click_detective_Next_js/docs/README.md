# click_detective_nextjs 문서 안내

이 문서는 `share_project`의 UI·UX·CSS를 유지하면서 게임 데이터 처리를 `click_detective` FastAPI로 연결한 **현재 구현**을 설명합니다. 이전의 별도 디자인이나 명시적 메모 저장 방식이 아니라, 원본 화면과 700ms 자동 저장을 사용하는 구성을 기준으로 처음부터 작성했습니다.

프로젝트 위치는 `~/reverse/click_detective_nextjs`입니다. 명령은 Linux/Bash 기준이며, 코드와 검사 보고서 확인 기준일은 2026-11-13입니다.

## 1. 이 프로젝트를 한 문장으로 이해하기

**브라우저에서 보이는 모습과 사용 흐름은 원본을 유지하고, 사건 데이터·게임 판정·대사 생성·저장은 FastAPI에 맡깁니다.**

브라우저가 FastAPI의 비밀 API 키를 직접 사용하는 구조는 아닙니다. Next.js 서버가 중간에서 인증 정보를 붙여 요청합니다.

```text
사용자 브라우저
  → Next.js 화면 및 /api/detective 중계
    → click_detective FastAPI
      → 사건 데이터 · SQLite · LangGraph · 양자화 Qwen 및 어댑터
```

## 4. 자주 나오는 용어

| 용어          | 쉬운 설명                                                |
| ------------- | -------------------------------------------------------- |
| UI            | 버튼·카드·입력창 등 화면의 모양과 구성                   |
| UX            | 클릭·화면 이동·저장·오류 확인 등 사용 흐름               |
| API           | 다른 프로그램에 데이터를 요청하거나 행동을 전달하는 창구 |
| BFF           | 이 화면을 위해 Next.js 서버가 제공하는 중계 계층         |
| DTO           | API로 주고받는 JSON의 정해진 모양                        |
| state         | FastAPI가 반환한 한 수사의 공식 상태                     |
| revision      | 그 수사 상태의 저장 버전 번호                            |
| request_id    | 한 번의 행동을 식별하는 UUID                             |
| fixture       | 실제 모델을 로딩하지 않는 명시적 개발·검사 모드          |
| HttpOnly 쿠키 | 브라우저 JavaScript에서 읽지 못하도록 설정한 쿠키        |

## 5. 함께 알아둘 범위

원본 `share_project` 자체는 연결 대상으로 수정하지 않습니다. 새 프로젝트가 원본 화면을 사용합니다. 모델 가중치·어댑터·양자화·LangGraph의 실제 설정은 [백엔드 문서](../../click_detective/docs/README.md)에 있습니다.

fixture에서 화면과 API 검사가 통과했다는 사실과, 실제 GPU에서 Qwen 생성 품질이 검증됐다는 사실은 구분해서 읽으세요. 이 문서의 검사 수치는 기존 보고서를 확인한 결과이며, 문서를 다시 작성하기 위해 모델 학습이나 실제 추론을 실행한 것은 아닙니다.

기본 플레이에서는 모델 생성·검증이 실패해도 백엔드가 승인 원문 대사로 복구합니다. 쟁점 발견 여부와 대화 응답은 분리됩니다. [백엔드 응답 정책](../../click_detective/docs/12_질문_응답과_복구_정책.md)을 참고하세요.
