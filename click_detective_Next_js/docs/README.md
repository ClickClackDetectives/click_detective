# Next.js 문서 안내

`click_detective_Next_js`의 현재 구조를 기준으로 실행 방법, 화면 사용법, 처리 순서, 함수·클래스 선언을 설명합니다.

| 구분 | 실제 코드 위치 | 책임 |
| --- | --- | --- |
| 화면 | `components/기능명/` | 화면·팝업·입력·메뉴 |
| 화면용 게임 로직 | `app/game/기능명/` | React 상태·훅·요청 순서·타입 |
| 스타일 | `styles/` | 공통·화면별·반응형 CSS |
| 서버 중계 | `server/proxy/` | 허용 경로·쿠키·서비스 키·입력·응답 |
| 공통 요청 | `shared/api/` | 브라우저 JSON 요청과 자산 주소 변환 |

게임 규칙·공식 저장·AI 에이전트는 [FastAPI](../../click_detective_FastAPI/docs/README.md)가 담당합니다. 이 문서에서 말하는 게임 로직은 화면의 상태와 요청을 연결하는 프런트엔드 코드입니다.

## 문서 구성 원칙

설치, 사용법, 코드 설명, 검증 결과는 각각 한 곳에서 관리합니다. 코드 설명서는 `화면 / 게임로직 / 서버 / 검사`로 나누고 각 파일의 실제 함수 선언을 코드 블록으로 보여줍니다. 입력은 `@param`, 반환은 `@returns` 설명을 기준으로 읽습니다.

이전 루트의 번호 문서 9개는 이동 안내만 중복하므로 정리했습니다. 이 목차에서 주제별 본문으로 바로 이동하세요.
