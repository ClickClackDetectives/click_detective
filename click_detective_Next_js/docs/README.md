# Next.js 문서 안내

| 3 | [폴더 구조](구조/폴더_구조.md) | 기능별 파일 위치와 수정 기준 |

발표할 때는 **동작 순서 → 코드 설명서의 수사 상태 → 서버 중계** 순서로 설명하면 됩니다. 코드 설명서는 함수의 본문 대신 실제 선언과 역할을 보여줍니다.

AI 전처리·생성·검증 에이전트는 FastAPI에서 실행됩니다. 관련 내용은 [FastAPI 문서](../../click_detective_FastAPI/docs/README.md)를 참고하세요. 기존 번호 문서는 새 문서로 이동하는 안내를 제공합니다.
