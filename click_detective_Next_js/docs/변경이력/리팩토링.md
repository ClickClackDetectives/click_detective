# 기능별 구조로 리팩토링

## 변경 목적

큰 파일을 화면·상태·서버 요청 단위로 나누고, 초보자가 담당 파일을 찾기 쉽게 정리했습니다. 함수·클래스는 JSDoc에 역할·파라미터·반환값을 설명합니다. TS·TSX·MJS·CSS 소스 파일은 주석 포함 250줄 이내이며 자동 검사로 유지합니다.

## 주요 경로 변경

| 이전 | 현재 실제 구현 |
| --- | --- |
| `components/case-app.tsx` | `features/application/case-app.tsx` |
| `components/screens/*` | 각 `features/기능명/*-screen.tsx` |
| `hooks/use-case-game.ts` | `features/investigation/use-case-game.ts` |
| 훅 내부의 복원·팝업·자동 저장 효과 | `use-restore-game.ts`, `use-dialog-effects.ts`, `features/notes/use-notes-autosave.ts` |
| `hooks/use-screen-view.ts` | `features/materials/use-screen-view.ts` |
| `lib/case.ts`의 타입·자료 | `features/catalog/types.ts`, `catalog.ts`, `features/investigation/types.ts` |
| `lib/game-client.ts` | `features/investigation/game-client.ts`, `commands.ts`, `documents.ts` |
| `lib/client-api.ts` | `shared/api/client.ts` |
| `lib/server/proxy-policy.ts` | `server/proxy/policy.ts` |
| 큰 API Route Handler | `server/proxy/handle.ts`, `request.ts`, `responses.ts` |
| 긴 통합·UI 검사 스크립트 | `scripts/integration/`, `scripts/ui/` |
| 큰 CSS | 기존 import 순서를 보존한 하위 CSS 파일 |

이전 `components`, `hooks`, `lib`는 새 구현을 다시 내보내므로 기존 import도 사용할 수 있습니다. 새 기능이나 수정은 새 경로에 작성합니다.

## 유지한 동작

기존 화면 문구·DOM·클래스·반응형 CSS·메뉴·오프닝·자료 팝업·700ms 메모 저장·API 계약·쿠키 정책·요청 순서·실패 복구를 유지합니다. 게임 규칙과 AI 에이전트는 FastAPI에 남아 있습니다. 프런트엔드에 에이전트 실행 계층을 추가하지 않습니다.

## 검증 기록

2026-11-16에 현재 작업 사본으로 실행했습니다.

| 확인 항목 | 결과 |
| --- | --- |
| `npm test` | 검사 파일 5개 통과: 코드 규칙·요청 복구·경로 정책·프로세스 정리·UI 계약 |
| `npm run typecheck` | 통과 |
| 추가 미사용 변수·파라미터 검사 | 통과 |
| `npm run build` | 배포용 빌드 통과 |
| `npm run test:ui` | 정상 종료 코드 0 |
| Next.js → FastAPI | 실제 HTTP 요청 149건 통과, 전체 수사 진행률·고발 점수 100 |
| 이전 화면과 비교 | 데스크톱·검색·모바일 18개 화면의 캡처 픽셀 일치 |
| 브라우저 조작 | 새 수사·오프닝, 자료 열람·첨부, 심문, 메모 저장, 새로고침 복원 5개 검사 통과 |
| 브라우저 실행 오류 | 없음 |
| 문서 상대 경로 | 잘못된 파일 링크 없음 |

화면 비교에는 리팩토링 직전 소스의 별도 사본을 사용했습니다. 같은 fixture 수사 상태와 로컬 글꼴 조건에서 비교했으며 외부 웹폰트 요청은 차단했습니다. 생성한 보고서는 `.reports/integration.json`, `.reports/ui/comparison.json`과 화면 PNG입니다. 보고서·실행용 임시 사본은 버전 관리에 포함하지 않습니다.

이 결과는 fixture 환경의 게임·화면·연결 검증입니다. 실제 GPU·LLM 생성 품질은 검사하지 않았습니다. 실행 방법과 환경변수는 [검사 안내](../테스트/검사와_오류해결.md)를 참고하세요.
