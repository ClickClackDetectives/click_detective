# 리팩토링 내용과 이전 파일의 현재 위치

큰 파일을 나누고 화면·게임 상태·스타일·서버 중계의 위치를 구분했습니다. 이름 있는 함수·클래스는 JSDoc에 역할·파라미터·반환값을 적고, TS·TSX·MJS·CSS 소스는 주석 포함 250줄 이내로 관리합니다.

## 최종 구조

| 위치 | 책임 |
| --- | --- |
| `components/기능명/` | 실제 화면·팝업·메뉴 |
| `app/game/기능명/` | 화면용 상태·요청·훅·타입·표시 보조 |
| `styles/` | 모든 CSS |
| `server/proxy/` | FastAPI 중계의 경로·입력·인증·응답 |
| `shared/api/` | 브라우저 공통 요청 |

이전 `features` 폴더는 사용하지 않습니다. `app` 안에 CSS나 화면 컴포넌트를 섞어 두지 않고, `app/page.tsx`와 `layout.tsx`가 화면·스타일의 진입점 역할을 합니다.

## 파일을 찾는 표

| 이전 위치 | 실제 구현 위치 |
| --- | --- |
| `components/case-app.tsx` | `components/application/case-app.tsx` |
| `components/screens/*-screen.tsx` | `components/기능명/*-screen.tsx` |
| `hooks/use-case-game.ts` | `app/game/investigation/use-case-game.ts` |
| 훅 내부의 초기 복원 | `app/game/investigation/use-restore-game.ts` |
| 훅 내부의 팝업·스크롤 효과 | `app/game/investigation/use-dialog-effects.ts` |
| 훅 내부의 메모 자동 저장 | `app/game/notes/use-notes-autosave.ts` |
| `hooks/use-screen-view.ts` | `app/game/materials/use-screen-view.ts` |
| `lib/case.ts`의 타입·자료 | `app/game/catalog/`, `app/game/investigation/types.ts` |
| `lib/game-client.ts` | `app/game/investigation/game-client.ts`, `commands.ts`, `documents.ts` |
| `lib/client-api.ts` | `shared/api/client.ts` |
| `lib/server/proxy-policy.ts` | `server/proxy/policy.ts` |
| API route 내부의 큰 중계 함수 | `server/proxy/handle.ts`, `request.ts`, `responses.ts` |
| `app/globals.css`, `app/styles/` | `styles/globals.css`, `styles/` |
| 긴 검사 스크립트 | `scripts/integration/`, `scripts/ui/` |

`components` 바로 아래의 예전 단일 파일, `components/screens/`, `hooks/`, `lib/`에는 새 구현을 다시 내보내는 호환 파일이 남아 있습니다. 실제 기능 수정은 위 표의 새 위치에서 합니다.

## 유지한 동작

기존 화면 문구·클래스·반응형 CSS·메뉴·오프닝·자료 팝업·700ms 메모 저장·API 계약·쿠키 정책·요청 순서·실패 복구를 유지했습니다. 게임 규칙과 공식 저장·AI 에이전트는 FastAPI가 담당합니다.

## 문서 재구성

루트의 이동 안내용 번호 문서 9개를 정리하고 주제별 본문으로 통합했습니다. 코드 참조도 `화면 / 게임로직 / 서버 / 검사`로 구분하여 실제 소스의 선언과 JSDoc에서 다시 작성했습니다. 이전 경로 표를 제외한 사용 설명과 코드 링크는 현재 구조를 사용합니다.

구체적인 실행 결과는 [검증 기록](../테스트/검증_기록.md)에 한 번만 보관합니다.
