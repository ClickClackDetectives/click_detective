# 브라우저 공통 요청과 오류

api는 같은 사이트의 /api/detective 경로에 JSON을 요청합니다. assetUrl은 백엔드 자산 주소를 같은 출처의 중계 주소로 바꿉니다.

## 읽는 기준

아래 코드는 현재 소스의 선언에서 본문을 제외한 것입니다. 입력과 반환 설명은 해당 함수의 JSDoc을 기준으로 정리했습니다. `Props`는 각 화면 파일에 정의된 입력 타입이며, 타입의 전체 필드는 소스 링크에서 확인합니다.

## shared/api/error.ts

[소스 열기](../../../shared/api/error.ts)

### ApiError

```ts
export class ApiError extends Error
```

역할: 화면이 사용하는 오류입니다. API 키나 서버 내부 스택은 포함하지 않습니다.

입력:

- `message`: 사용자에게 보여줄 안내.
- `status`: HTTP 상태 코드.
- `code`: 오류를 구분할 코드.
- `fields`: 입력 항목별 공개 오류.

반환: ApiError 객체.

### ApiError.constructor

```ts
constructor(message: string, status: number, code: string, fields = {})
```

역할: 객체에서 함께 사용할 값과 초기 상태를 준비한다.

선언 위치: `ApiError` 내부.

입력:

- `message`: 사용자에게 보여줄 안내.
- `status`: HTTP 상태 코드.
- `code`: 오류를 구분할 코드.

반환: 없음. 객체의 초기값을 저장한다.

## shared/api/client.ts

[소스 열기](../../../shared/api/client.ts)

### api

```ts
export async function api<T>(path: string, method = 'GET', body?: unknown): Promise<T>
```

역할: 같은 출처의 BFF로 수사 요청을 보낸다. 접근 토큰이 만료되면 같은 계정과 수사를 확인하고 한 번 재전송한다.

입력:

- `path`: 호출 경로나 파일 경로.
- `method`: HTTP 요청 메서드.
- `body`: 전송할 요청 본문.

반환: 서버가 반환한 JSON 응답.

### assetUrl

```ts
export function assetUrl(path: string): string
```

역할: 백엔드가 준 자산 경로를 같은 출처 프록시 경로로 바꿉니다. 임의 외부 URL은 받지 않습니다.

입력:

- `path`: 호출 경로나 파일 경로.

반환: 같은 출처의 자산 프록시 경로. 허용되지 않으면 빈 문자열.
