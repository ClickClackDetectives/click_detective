# Next.js 페이지와 Route Handler

page.tsx가 화면을 시작하고 layout.tsx가 HTML 틀과 styles/globals.css를 적용합니다. API route는 공통 handle을 연결합니다.

## 읽는 기준

아래 코드는 현재 소스의 선언에서 본문을 제외한 것입니다. 입력과 반환 설명은 해당 함수의 JSDoc을 기준으로 정리했습니다. `Props`는 각 화면 파일에 정의된 입력 타입이며, 타입의 전체 필드는 소스 링크에서 확인합니다.

## app/api/detective/[...segments]/route.ts

[소스 열기](../../../app/api/detective/[...segments]/route.ts)

GET·POST·PUT을 `server/proxy/handle.ts`의 `handle`로 내보냅니다. Node.js 런타임과 동적 응답 설정도 이 파일에 있습니다.

## app/assets/[...asset]/route.ts

[소스 열기](../../../app/assets/[...asset]/route.ts)

### GET

```ts
export async function GET(request: NextRequest, context: { params: Promise<{ asset: string[] }> })
```

역할: 원본 자산 URL은 유지하고 실제 파일은 인증된 FastAPI에서 받습니다.

입력:

- `request`: 확인하거나 전달할 요청.
- `context`: Next.js가 전달한 비동기 경로 파라미터.

반환: 자산을 전달하는 HTTP 응답.

## app/layout.tsx

[소스 열기](../../../app/layout.tsx)

### RootLayout

```ts
export default function RootLayout({ children }: Readonly<{ children: React.ReactNode }>)
```

역할: 모든 화면에 공통 HTML과 스타일을 적용한다.

입력:

- `props`: 화면에 전달한 상태와 사용자 행동 함수.
- `props.children`: 공통 레이아웃 안에 표시할 화면.

반환: 표시할 React 화면. 표시할 내용이 없으면 null.
