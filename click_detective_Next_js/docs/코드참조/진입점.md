# Next.js 주소와 진입점

Next.js가 파일 경로를 주소로 사용하는 부분입니다. catch-all API route는 GET·POST·PUT을 `handle`로 재내보내며, 자산 route는 같은 중계 함수를 호출합니다.

선언은 현재 소스에서 본문을 제외해 옮겼습니다. 타입 이름은 같은 파일 또는 import한 타입 파일에서 확인할 수 있습니다.

## route.ts

[소스 보기](../../app/api/detective/[...segments]/route.ts)

타입·상수 또는 다른 구현의 재내보내기를 정의하는 파일입니다.

## route.ts

[소스 보기](../../app/assets/[...asset]/route.ts)

### GET

```ts
export async function GET(request: NextRequest, context: { params: Promise<{ asset: string[] }> })
```

원본 자산 URL은 유지하고 실제 파일은 인증된 FastAPI에서 받습니다.

입력:

- `request`: 확인하거나 전달할 요청.
- `context`: Next.js가 전달한 비동기 경로 파라미터.

반환: 자산을 전달하는 HTTP 응답.

## layout.tsx

[소스 보기](../../app/layout.tsx)

### RootLayout

```ts
export default function RootLayout({ children }: Readonly<{ children: React.ReactNode }>)
```

모든 화면에 공통 HTML과 스타일을 적용한다.

입력:

- `props`: 화면에 전달한 상태와 사용자 행동 함수.
- `props.children`: 공통 레이아웃 안에 표시할 화면.

반환: 표시할 React 화면. 표시할 내용이 없으면 null.
