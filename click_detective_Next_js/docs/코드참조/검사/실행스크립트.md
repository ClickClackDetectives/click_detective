# 검사 실행과 보고서

통합 검사와 선택적인 브라우저 검사를 실행하고 보고서·임시 자원을 정리합니다.

## 읽는 기준

아래 코드는 현재 소스의 선언에서 본문을 제외한 것입니다. 입력과 반환 설명은 해당 함수의 JSDoc을 기준으로 정리했습니다. `Props`는 각 화면 파일에 정의된 입력 타입이며, 타입의 전체 필드는 소스 링크에서 확인합니다.

## scripts/test-integration.mjs

[소스 열기](../../../scripts/test-integration.mjs)

### backendPython

```ts
async function backendPython(backend)
```

역할: 사용할 백엔드 Python을 환경변수 또는 기존 가상환경에서 찾는다.

입력:

- `backend`: FastAPI 프로젝트 폴더.

반환: 백엔드 Python 명령 또는 실행 파일 경로.

### main

```ts
async function main()
```

역할: fixture 서버와 빌드된 Next.js를 연결하여 전체 게임을 확인한다.

입력: 없음.

반환: 검사와 보고서 저장 및 임시 자원 정리가 끝나면 완료되는 Promise.

## scripts/verify-original-ui.mjs

[소스 열기](../../../scripts/verify-original-ui.mjs)

### runUiChecks

```ts
export async function runUiChecks({ project, temp, base, state, cookies, start, ready })
```

역할: 같은 상태의 비교 소스와 현재 화면을 실제 브라우저로 확인한다.

입력:

- `props`: 검사에 사용할 설정과 데이터.
- `props.project`: Next.js 프로젝트 폴더.
- `props.temp`: 검사 전용 임시 폴더.
- `props.base`: 테스트 서버의 기본 주소.
- `props.state`: 서버에서 확인한 현재 수사 상태.
- `props.cookies`: 검사 수사의 HttpOnly 쿠키 문자열.
- `props.start`: 검사 서버를 시작하는 함수.
- `props.ready`: 서버 준비를 기다리는 함수.

반환: 화면 비교·상호작용 검사와 보고서 저장이 끝나면 완료되는 Promise.
