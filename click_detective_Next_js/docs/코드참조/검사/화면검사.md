# 브라우저 화면과 조작 검사

동일한 수사 데이터를 제공한 이전 화면과 현재 화면을 캡처하고, 새 수사·자료 열람·심문·메모를 조작합니다.

## 읽는 기준

아래 코드는 현재 소스의 선언에서 본문을 제외한 것입니다. 입력과 반환 설명은 해당 함수의 JSDoc을 기준으로 정리했습니다. `Props`는 각 화면 파일에 정의된 입력 타입이며, 타입의 전체 필드는 소스 링크에서 확인합니다.

## scripts/ui/compare-screens.mjs

[소스 열기](../../../scripts/ui/compare-screens.mjs)

### compareScreens

```ts
export async function compareScreens({ actual, original, compare })
```

역할: 데스크톱·검색·모바일 화면을 같은 순서로 전환하고 비교한다.

입력:

- `props`: 검사에 사용할 설정과 데이터.
- `props.actual`: 현재 앱의 브라우저 페이지.
- `props.original`: 비교 대상의 브라우저 페이지.
- `props.compare`: 두 화면을 캡처해 비교하는 함수.

반환: 전체 화면 비교가 끝나면 완료되는 Promise.

## scripts/ui/interactions.mjs

[소스 열기](../../../scripts/ui/interactions.mjs)

### checkInteractions

```ts
export async function checkInteractions({ actual, actualContext, base, report })
```

역할: 새 수사·오프닝·증거 제시·심문·메모 자동 저장·복원을 확인한다.

입력:

- `props`: 검사에 사용할 설정과 데이터.
- `props.actual`: 현재 앱의 브라우저 페이지.
- `props.actualContext`: 현재 앱의 인증 쿠키를 가진 브라우저 문맥.
- `props.base`: 테스트 서버의 기본 주소.
- `props.report`: 검사 결과를 모을 객체.

반환: 사용자 동작 검사가 끝나면 완료되는 Promise.

## scripts/ui/reference.mjs

[소스 열기](../../../scripts/ui/reference.mjs)

### prepareReference

```ts
export async function prepareReference({ project, temp, start, ready })
```

역할: 비교할 소스의 격리된 사본을 만들고 별도 포트로 실행한다.

입력:

- `props`: 검사에 사용할 설정과 데이터.
- `props.project`: Next.js 프로젝트 폴더.
- `props.temp`: 검사 전용 임시 폴더.
- `props.start`: 검사 서버를 시작하는 함수.
- `props.ready`: 서버 준비를 기다리는 함수.

반환: 실행한 비교 서버 주소.

### openBrowser

```ts
export async function openBrowser(project)
```

역할: 같은 브라우저와 글꼴 설정으로 비교할 Chromium을 실행한다.

입력:

- `project`: Next.js 프로젝트 폴더.

반환: 검사에 사용할 Chromium 브라우저.

## scripts/ui/screenshots.mjs

[소스 열기](../../../scripts/ui/screenshots.mjs)

### settle

```ts
export async function settle(page)
```

역할: 글꼴과 이미지 표시가 끝날 때까지 기다린다.

입력:

- `page`: 확인할 브라우저 페이지.

반환: 이미지와 글꼴 준비가 끝나면 완료되는 Promise.

### screenshotComparer

```ts
export function screenshotComparer(actual, original, report, output)
```

역할: 같은 상태의 두 페이지를 캡처하는 비교 함수를 만든다.

입력:

- `actual`: 현재 앱의 브라우저 페이지.
- `original`: 비교 대상의 브라우저 페이지.
- `report`: 검사 결과를 모을 객체.
- `output`: 스크린샷을 저장할 폴더.

반환: 화면 이름을 받아 두 페이지를 비교하는 함수.

### screenshotComparer.compare

```ts
async function compare(name)
```

역할: 같은 화면을 캡처하고 픽셀 일치 여부를 기록한다.

선언 위치: `screenshotComparer` 내부.

입력:

- `name`: 파일·사례·화면의 이름.

반환: 두 화면의 캡처와 일치 여부 기록이 끝나면 완료되는 Promise.
