# 증언과 심문 기록

TestimoniesScreen → WitnessSection → StatementEntry 순서로 목록·인물·진술을 표시합니다.

## 읽는 기준

아래 코드는 현재 소스의 선언에서 본문을 제외한 것입니다. 입력과 반환 설명은 해당 함수의 JSDoc을 기준으로 정리했습니다. `Props`는 각 화면 파일에 정의된 입력 타입이며, 타입의 전체 필드는 소스 링크에서 확인합니다.

## components/testimony/statement-entry.tsx

[소스 열기](../../../components/testimony/statement-entry.tsx)

이 파일의 타입: `Props`.

### StatementEntry

```ts
export function StatementEntry({ state, item, openEvidence, navigateTo }: Props)
```

역할: 획득한 진술과 수정 이력, 출처, 타임라인 이동을 표시한다.

입력:

- `props`: 화면에 전달한 상태와 사용자 행동 함수.
- `props.state`: 서버에서 확인한 현재 수사 상태.
- `props.item`: 확인할 자료 또는 진술.
- `props.openEvidence`: 자료를 열람하고 문서 팝업을 여는 함수.
- `props.navigateTo`: 선택한 화면으로 이동하는 함수.

반환: 표시할 React 화면. 표시할 내용이 없으면 null.

## components/testimony/witness-section.tsx

[소스 열기](../../../components/testimony/witness-section.tsx)

이 파일의 타입: `Props`.

### WitnessSection

```ts
export function WitnessSection({ state, w, section, busy, openEvidence, navigateTo }: Props)
```

역할: 한 인물의 최초 진술, 확보 증언과 심문 대화를 표시한다.

입력:

- `props`: 화면에 전달한 상태와 사용자 행동 함수.
- `props.state`: 서버에서 확인한 현재 수사 상태.
- `props.w`: 한 인물의 서버 조회 결과.
- `props.section`: 선택한 증언 분류.
- `props.busy`: 요청 처리 중인지 여부.
- `props.openEvidence`: 자료를 열람하고 문서 팝업을 여는 함수.
- `props.navigateTo`: 선택한 화면으로 이동하는 함수.

반환: 표시할 React 화면. 표시할 내용이 없으면 null.
