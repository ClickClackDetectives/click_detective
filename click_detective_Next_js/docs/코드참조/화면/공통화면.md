# 앱 조립과 공통 화면

Page → OriginalAppLoader → CaseApp → InvestigationWorkspace 순서로 화면을 조립합니다. 메뉴와 팝업은 전달받은 상태·행동 함수를 사용합니다.

## 읽는 기준

아래 코드는 현재 소스의 선언에서 본문을 제외한 것입니다. 입력과 반환 설명은 해당 함수의 JSDoc을 기준으로 정리했습니다. `Props`는 각 화면 파일에 정의된 입력 타입이며, 타입의 전체 필드는 소스 링크에서 확인합니다.

## components/application/app-header.tsx

[소스 열기](../../../components/application/app-header.tsx)

이 파일의 타입: `Props`.

### AppHeader

```ts
export function AppHeader({ view, state, inProgress, navigateTo, setModal }: Props)
```

역할: 현재 화면에 맞는 상단 메뉴를 표시한다.

입력:

- `props`: 화면에 전달한 상태와 사용자 행동 함수.
- `props.view`: 현재 선택한 화면 이름.
- `props.state`: 서버에서 확인한 현재 수사 상태.
- `props.inProgress`: 진행 중인 수사가 있으면 해당 상태, 없으면 null 또는 false.
- `props.navigateTo`: 선택한 화면으로 이동하는 함수.
- `props.setModal`: 안내 팝업을 열거나 닫는 함수.

반환: 표시할 React 화면. 표시할 내용이 없으면 null.

## components/application/game-dialog.tsx

[소스 열기](../../../components/application/game-dialog.tsx)

이 파일의 타입: `Props`.

### GameDialog

```ts
export function GameDialog({
  modal,
  busy,
  setModal,
  updateGame,
  form,
  navigateTo,
  startInvestigation,
}: Props)
```

역할: 고발 확인·수사 초기화·도움말 팝업을 표시한다.

입력:

- `props`: 화면에 전달한 상태와 사용자 행동 함수.
- `props.modal`: 열린 안내 팝업 이름.
- `props.busy`: 요청 처리 중인지 여부.
- `props.setModal`: 안내 팝업을 열거나 닫는 함수.
- `props.updateGame`: 행동 이름과 입력을 서버에 보내고 최신 상태를 적용하는 함수.
- `props.form`: 고발 대상·동기·방법·근거 입력.
- `props.navigateTo`: 선택한 화면으로 이동하는 함수.
- `props.startInvestigation`: 기존 수사를 이어가거나 새 수사를 만드는 함수.

반환: 표시할 React 화면. 표시할 내용이 없으면 null.
