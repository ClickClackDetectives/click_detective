# 메모 입력 화면

입력 중인 메모와 저장 상태를 보여줍니다. 자동 저장의 실행은 app/game/notes의 훅이 담당합니다.

## 읽는 기준

아래 코드는 현재 소스의 선언에서 본문을 제외한 것입니다. 입력과 반환 설명은 해당 함수의 JSDoc을 기준으로 정리했습니다. `Props`는 각 화면 파일에 정의된 입력 타입이며, 타입의 전체 필드는 소스 링크에서 확인합니다.

## components/notes/notes-screen.tsx

[소스 열기](../../../components/notes/notes-screen.tsx)

이 파일의 타입: `Props`.

### NotesScreen

```ts
export function NotesScreen({
  state,
  notes,
  setNotes,
  noteStatus,
  busy,
  updateGame,
  setNoteStatus,
}: Props)
```

역할: 메모 입력창과 저장 상태를 표시한다.

입력:

- `props`: 화면에 전달한 상태와 사용자 행동 함수.
- `props.state`: 서버에서 확인한 현재 수사 상태.
- `props.notes`: 현재 입력 중인 수사 메모.
- `props.setNotes`: 메모 입력값을 바꾸는 함수.
- `props.noteStatus`: 메모 저장 상태를 보여주는 안내 문구.
- `props.busy`: 요청 처리 중인지 여부.
- `props.updateGame`: 행동 이름과 입력을 서버에 보내고 최신 상태를 적용하는 함수.
- `props.setNoteStatus`: 메모 저장 상태 안내를 바꾸는 함수.

반환: 표시할 React 화면. 표시할 내용이 없으면 null.
