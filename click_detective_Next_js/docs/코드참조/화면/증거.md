# 증거 목록과 문서 팝업

EvidenceScreen에서 검색·분류 결과를 보여주고, openEvidence가 받은 상세 자료를 EvidenceDialog로 표시합니다.

## 읽는 기준

아래 코드는 현재 소스의 선언에서 본문을 제외한 것입니다. 입력과 반환 설명은 해당 함수의 JSDoc을 기준으로 정리했습니다. `Props`는 각 화면 파일에 정의된 입력 타입이며, 타입의 전체 필드는 소스 링크에서 확인합니다.

## components/materials/evidence-dialog.tsx

[소스 열기](../../../components/materials/evidence-dialog.tsx)

이 파일의 타입: `Props`.

### EvidenceDialog

```ts
export function EvidenceDialog({ selectedDoc, setDoc, setAttachment, navigateTo }: Props)
```

역할: 확보한 문서 본문과 이미지, 자료 제시 버튼을 팝업으로 표시한다.

입력:

- `props`: 화면에 전달한 상태와 사용자 행동 함수.
- `props.selectedDoc`: 팝업에 표시할 문서 본문과 메타데이터.
- `props.setDoc`: 문서 팝업을 열거나 닫는 함수.
- `props.setAttachment`: 심문에 첨부할 자료를 바꾸는 함수.
- `props.navigateTo`: 선택한 화면으로 이동하는 함수.

반환: 표시할 React 화면. 표시할 내용이 없으면 null.

## components/materials/evidence-screen.tsx

[소스 열기](../../../components/materials/evidence-screen.tsx)

이 파일의 타입: `Props`.

### EvidenceScreen

```ts
export function EvidenceScreen({
  state,
  filter,
  setFilter,
  busy,
  openEvidence,
  updateGame,
}: Props)
```

역할: 장소와 검색 조건에 맞는 증거 목록을 표시한다.

입력:

- `props`: 화면에 전달한 상태와 사용자 행동 함수.
- `props.state`: 서버에서 확인한 현재 수사 상태.
- `props.filter`: 자료 검색창의 입력값.
- `props.setFilter`: 자료 검색 입력값을 바꾸는 함수.
- `props.busy`: 요청 처리 중인지 여부.
- `props.openEvidence`: 자료를 열람하고 문서 팝업을 여는 함수.
- `props.updateGame`: 행동 이름과 입력을 서버에 보내고 최신 상태를 적용하는 함수.

반환: 표시할 React 화면. 표시할 내용이 없으면 null.
