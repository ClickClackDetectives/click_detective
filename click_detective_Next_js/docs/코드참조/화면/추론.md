# 자료 선택과 확보 추론 화면

InferenceScreen에서 자료 2~4개를 선택해 연결을 요청합니다. 확보한 결과 카드는 DerivedList가 표시합니다.

## 읽는 기준

아래 코드는 현재 소스의 선언에서 본문을 제외한 것입니다. 입력과 반환 설명은 해당 함수의 JSDoc을 기준으로 정리했습니다. `Props`는 각 화면 파일에 정의된 입력 타입이며, 타입의 전체 필드는 소스 링크에서 확인합니다.

## components/inference/derived-list.tsx

[소스 열기](../../../components/inference/derived-list.tsx)

이 파일의 타입: `Props`.

### DerivedList

```ts
export function DerivedList({ state, openEvidence, title, open }: Props)
```

역할: 이미 확보한 추론 문서와 직접·원본 근거를 표시한다.

입력:

- `props`: 화면에 전달한 상태와 사용자 행동 함수.
- `props.state`: 서버에서 확인한 현재 수사 상태.
- `props.openEvidence`: 자료를 열람하고 문서 팝업을 여는 함수.
- `props.title`: 출처의 표시 제목을 만드는 함수.
- `props.open`: 선택한 출처를 여는 함수.

반환: 표시할 React 화면. 표시할 내용이 없으면 null.

## components/inference/inference-screen.tsx

[소스 열기](../../../components/inference/inference-screen.tsx)

이 파일의 타입: `Props`.

### InferenceScreen

```ts
export function InferenceScreen({ state, busy, updateGame, openEvidence, navigateTo }: Props)
```

역할: 연결할 자료 선택과 확보한 추론을 표시한다.

입력:

- `props`: 화면에 전달한 상태와 사용자 행동 함수.
- `props.state`: 서버에서 확인한 현재 수사 상태.
- `props.busy`: 요청 처리 중인지 여부.
- `props.updateGame`: 행동 이름과 입력을 서버에 보내고 최신 상태를 적용하는 함수.
- `props.openEvidence`: 자료를 열람하고 문서 팝업을 여는 함수.
- `props.navigateTo`: 선택한 화면으로 이동하는 함수.

반환: 표시할 React 화면. 표시할 내용이 없으면 null.

### InferenceScreen.title

```ts
function title(ref: SourceRef)
```

역할: 출처의 화면용 제목을 만든다.

선언 위치: `InferenceScreen` 내부.

입력:

- `ref`: 자료 종류와 ID가 담긴 출처.

반환: 출처의 화면용 제목 문자열.

### InferenceScreen.open

```ts
function open(ref: SourceRef)
```

역할: 선택한 출처의 자료를 연다.

선언 위치: `InferenceScreen` 내부.

입력:

- `ref`: 자료 종류와 ID가 담긴 출처.

반환: 없음. 선택한 자료를 여는 비동기 작업을 시작한다.

### InferenceScreen.toggle

```ts
function toggle(ref: SourceRef)
```

역할: 선택한 자료를 추가하거나 해제한다.

선언 위치: `InferenceScreen` 내부.

입력:

- `ref`: 자료 종류와 ID가 담긴 출처.

반환: 없음. 선택한 자료 목록을 바꾼다.

### InferenceScreen.connect

```ts
async function connect()
```

역할: 현재 선택한 자료로 추론 생성을 요청한다.

선언 위치: `InferenceScreen` 내부.

입력: 없음.

반환: 추론 요청과 결과 안내 처리가 끝나면 완료되는 Promise.
