# 발견한 쟁점 화면

서버가 확인한 심문 쟁점과 출처를 표시합니다. 출처를 누르면 확보한 문서를 엽니다.

## 읽는 기준

아래 코드는 현재 소스의 선언에서 본문을 제외한 것입니다. 입력과 반환 설명은 해당 함수의 JSDoc을 기준으로 정리했습니다. `Props`는 각 화면 파일에 정의된 입력 타입이며, 타입의 전체 필드는 소스 링크에서 확인합니다.

## components/findings/findings-screen.tsx

[소스 열기](../../../components/findings/findings-screen.tsx)

이 파일의 타입: `Props`.

### key

```ts
function key(ref: SourceRef)
```

역할: 자료 종류와 ID를 합쳐 목록 식별자를 만든다.

입력:

- `ref`: 자료 종류와 ID가 담긴 출처.

반환: 자료 종류와 ID를 합친 문자열.

### FindingsScreen

```ts
export function FindingsScreen({ state, openEvidence }: Props)
```

역할: 심문에서 확인한 사실만 표시한다. 자료 연결과 추론 생성은 별도 화면에서 처리한다.

입력:

- `props`: 화면에 전달한 상태와 사용자 행동 함수.
- `props.state`: 서버에서 확인한 현재 수사 상태.
- `props.openEvidence`: 자료를 열람하고 문서 팝업을 여는 함수.

반환: 표시할 React 화면. 표시할 내용이 없으면 null.

### FindingsScreen.title

```ts
function title(ref: SourceRef)
```

역할: 출처의 화면용 제목을 만든다.

선언 위치: `FindingsScreen` 내부.

입력:

- `ref`: 자료 종류와 ID가 담긴 출처.

반환: 확보 자료의 제목. 찾지 못하면 undefined.

### FindingsScreen.open

```ts
function open(ref: SourceRef)
```

역할: 선택한 출처의 자료를 연다.

선언 위치: `FindingsScreen` 내부.

입력:

- `ref`: 자료 종류와 ID가 담긴 출처.

반환: 없음. 선택한 자료를 여는 비동기 작업을 시작한다.
