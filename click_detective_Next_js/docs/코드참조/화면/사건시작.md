# 홈·사건 선택·브리핑·오프닝

홈에서 수사를 시작하고 브리핑으로 이동합니다. 오프닝 재생 여부는 현재 수사 ID별로 관리합니다.

## 읽는 기준

아래 코드는 현재 소스의 선언에서 본문을 제외한 것입니다. 입력과 반환 설명은 해당 함수의 JSDoc을 기준으로 정리했습니다. `Props`는 각 화면 파일에 정의된 입력 타입이며, 타입의 전체 필드는 소스 링크에서 확인합니다.

## components/catalog/briefing-screen.tsx

[소스 열기](../../../components/catalog/briefing-screen.tsx)

이 파일의 타입: `Props`.

### BriefingScreen

```ts
export function BriefingScreen({ state, navigateTo }: Props)
```

역할: 사건 개요와 오프닝 재생 버튼을 표시한다.

입력:

- `props`: 화면에 전달한 상태와 사용자 행동 함수.
- `props.state`: 서버에서 확인한 현재 수사 상태.
- `props.navigateTo`: 선택한 화면으로 이동하는 함수.

반환: 표시할 React 화면. 표시할 내용이 없으면 null.

## components/catalog/cases-screen.tsx

[소스 열기](../../../components/catalog/cases-screen.tsx)

이 파일의 타입: `Props`.

### CasesScreen

```ts
export function CasesScreen({ busy, ready, inProgress, startInvestigation, setModal }: Props)
```

역할: 사건 카드와 준비 중 사건 안내를 표시한다.

입력:

- `props`: 화면에 전달한 상태와 사용자 행동 함수.
- `props.busy`: 요청 처리 중인지 여부.
- `props.ready`: 최초 수사 복원 요청이 끝났는지 여부.
- `props.inProgress`: 진행 중인 수사가 있으면 해당 상태, 없으면 null 또는 false.
- `props.startInvestigation`: 기존 수사를 이어가거나 새 수사를 만드는 함수.
- `props.setModal`: 안내 팝업을 열거나 닫는 함수.

반환: 표시할 React 화면. 표시할 내용이 없으면 null.
