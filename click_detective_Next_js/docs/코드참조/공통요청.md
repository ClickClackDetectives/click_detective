# 브라우저 공통 요청

브라우저가 사용하는 같은 출처의 JSON 요청·오류·자산 주소 변환입니다.

선언은 현재 소스에서 본문을 제외해 옮겼습니다. 타입 이름은 같은 파일 또는 import한 타입 파일에서 확인할 수 있습니다.

## client.ts

[소스 보기](../../shared/api/client.ts)

### ApiError

```ts
export class ApiError extends Error
```

화면이 사용하는 오류입니다. API 키나 서버 내부 스택은 포함하지 않습니다.

입력:

- `message`: 사용자에게 보여줄 안내.
- `status`: HTTP 상태 코드.
- `code`: 오류를 구분할 코드.

반환: ApiError 객체.

### constructor

```ts
constructor(message: string, status: number, code: string)
```

객체에서 함께 사용할 값과 초기 상태를 준비한다.

입력:

- `message`: 사용자에게 보여줄 안내.
- `status`: HTTP 상태 코드.
- `code`: 오류를 구분할 코드.

반환: 없음. 객체의 초기값을 저장한다.

### api

```ts
export async function api<T>(path: string, method = 'GET', body?: unknown): Promise<T>
```

모든 브라우저 호출은 같은 출처의 Next.js BFF를 통합니다.

입력:

- `path`: 호출 경로나 파일 경로.
- `method`: HTTP 요청 메서드.
- `body`: 전송할 요청 본문.

반환: 서버가 반환한 JSON 응답.

### assetUrl

```ts
export function assetUrl(path: string): string
```

백엔드가 준 자산 경로를 같은 출처 프록시 경로로 바꿉니다. 임의 외부 URL은 받지 않습니다.

입력:

- `path`: 호출 경로나 파일 경로.

반환: 같은 출처의 자산 프록시 경로. 허용되지 않으면 빈 문자열.
