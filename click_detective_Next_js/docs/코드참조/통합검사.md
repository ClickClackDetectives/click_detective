# 전체 게임 연결 검사

임시 fixture 서버에 실제 HTTP 요청을 보내 인증·자료·수사·고발·저장을 검사합니다.

선언은 현재 소스에서 본문을 제외해 옮겼습니다. 타입 이름은 같은 파일 또는 import한 타입 파일에서 확인할 수 있습니다.

## api-checks.mjs

[소스 보기](../../scripts/integration/api-checks.mjs)

### prepareInvestigation

```ts
export async function prepareInvestigation(client)
```

API 인증·자산·쿠키·중복·버전·검색을 확인하고 수사를 준비한다.

입력:

- `client`: 쿠키와 최신 상태를 보관하는 통합 검사 클라이언트.

반환: 처음 생성한 수사 요청과 ID.

- `key`: 서버 간 인증에 사용할 비밀 키.
- `backend`: FastAPI 프로젝트 폴더.

### request

```ts
async request(
    route,
    { method = 'GET', body, status = 200, origin = this.base, headers = {} } = {},
  )
```

쿠키를 유지하며 HTTP 요청을 보내고 응답과 상태 코드를 검사한다.

입력:

- `route`: 호출할 API 경로.
- `props`: 검사에 사용할 설정과 데이터.
- `props.method`: HTTP 요청 메서드.
- `props.body`: 전송할 요청 본문.
- `props.status`: HTTP 상태 코드.
- `props.origin`: 브라우저가 보낸 Origin 헤더.
- `props.headers`: 추가 요청 헤더.

반환: 상태 코드를 확인하고 기록한 응답 JSON.

### act

```ts
async act(route, fields, method = 'POST')
```

UUID와 현재 저장 버전을 붙여 수사 행동을 실행한다.

입력:

- `route`: 호출할 API 경로.
- `fields`: 행동 요청에 추가할 입력값.
- `method`: HTTP 요청 메서드.

반환: 최신 수사 상태가 반영된 행동 응답.

### readCase

```ts
async readCase(name)
```

검사에 사용할 사건 JSON을 읽는다.

입력:

- `name`: 파일·사례·화면의 이름.

반환: 지정한 사건 파일의 JSON 객체.
