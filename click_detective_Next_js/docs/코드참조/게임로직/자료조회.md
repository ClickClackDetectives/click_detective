### useScreenView

```ts
export function useScreenView<T>(
  screen: string,
  state: GameState,
  query: Record<string, string>,
  initial: T,
)
```

역할: 원본 필터 UI는 유지하고 검색·분류 결과를 FastAPI에서 받아 표시합니다.

입력:

- `screen`: 검색할 화면 이름.
- `state`: 서버에서 확인한 현재 수사 상태.
- `query`: 화면에서 선택한 검색 조건.
- `initial`: 첫 응답 전 사용할 기본값.

반환: 서버의 화면 조회 결과와 오류 안내.
