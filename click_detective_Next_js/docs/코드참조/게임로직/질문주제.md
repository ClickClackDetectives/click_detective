# 공개 질문 주제

getInterviewTopics는 카탈로그에서 받은 해당 인물의 공개 질문 주제를 반환합니다.

## 읽는 기준

아래 코드는 현재 소스의 선언에서 본문을 제외한 것입니다. 입력과 반환 설명은 해당 함수의 JSDoc을 기준으로 정리했습니다. `Props`는 각 화면 파일에 정의된 입력 타입이며, 타입의 전체 필드는 소스 링크에서 확인합니다.

## app/game/interrogation/topics.ts

[소스 열기](../../../app/game/interrogation/topics.ts)

### getInterviewTopics

```ts
export function getInterviewTopics(speaker: SuspectId)
```

역할: 백엔드가 공개한 질문 주제만 원본 버튼으로 표시합니다.

입력:

- `speaker`: 질문 주제를 조회할 인물 ID.

반환: 선택한 인물의 공개 질문 주제 목록. 인물이 없으면 빈 배열.
