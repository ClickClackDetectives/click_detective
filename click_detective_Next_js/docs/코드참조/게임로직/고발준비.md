# 고발 준비도 표시

서버에서 받은 고발 기준·필수 추론 ID·준비도를 읽습니다. 이 함수들이 고발 결과를 채점하지는 않습니다.

## 읽는 기준

아래 코드는 현재 소스의 선언에서 본문을 제외한 것입니다. 입력과 반환 설명은 해당 함수의 JSDoc을 기준으로 정리했습니다. `Props`는 각 화면 파일에 정의된 입력 타입이며, 타입의 전체 필드는 소스 링크에서 확인합니다.

## app/game/accusation/requirements.ts

[소스 열기](../../../app/game/accusation/requirements.ts)

### installAccusation

```ts
export function installAccusation(minimum: number)
```

역할: 고발 준비도에 표시할 서버 기준을 보관한다.

입력:

- `minimum`: 서버가 알려준 고발 준비 표시 기준.

반환: 없음. 서버의 고발 표시 기준을 저장한다.

### getRequiredInferenceIds

```ts
export function getRequiredInferenceIds(state: GameState)
```

역할: 필수 ID는 실제 획득한 추론에 한해서 서버가 표시용으로 공개합니다.

입력:

- `state`: 서버에서 확인한 현재 수사 상태.

반환: 고발 근거에 필요한 확보 추론의 ID 목록.

### getAccusationReadiness

```ts
export function getAccusationReadiness(state: GameState)
```

역할: 서버가 알려준 고발 준비 상태를 읽는다.

입력:

- `state`: 서버에서 확인한 현재 수사 상태.

반환: 서버가 계산한 고발 준비도와 안내 정보.
