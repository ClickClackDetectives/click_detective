# 메모 자동 저장

입력이 700ms 멈추면 공통 요청 큐로 저장합니다. 저장 중 더 입력한 초안을 이전 응답으로 덮어쓰지 않게 확인합니다.

## 읽는 기준

아래 코드는 현재 소스의 선언에서 본문을 제외한 것입니다. 입력과 반환 설명은 해당 함수의 JSDoc을 기준으로 정리했습니다. `Props`는 각 화면 파일에 정의된 입력 타입이며, 타입의 전체 필드는 소스 링크에서 확인합니다.

## app/game/notes/use-notes-autosave.ts

[소스 열기](../../../app/game/notes/use-notes-autosave.ts)

### useNotesAutosave

```ts
export function useNotesAutosave({ state, notes, busy, setState, setNoteStatus }: Options)
```

역할: 입력이 멈추면 저장하고, 저장하지 않은 메모가 있으면 탭 종료를 알린다.

입력:

- `props`: 화면에 전달한 상태와 사용자 행동 함수.
- `props.state`: 서버에서 확인한 현재 수사 상태.
- `props.notes`: 현재 입력 중인 수사 메모.
- `props.busy`: 요청 처리 중인지 여부.
- `props.setState`: 서버 수사 상태를 화면에 반영하는 함수.
- `props.setNoteStatus`: 메모 저장 상태 안내를 바꾸는 함수.

반환: 없음. 메모 자동 저장과 종료 안내 효과를 등록한다.
