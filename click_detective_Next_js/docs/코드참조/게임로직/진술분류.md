# 증언 화면의 분류

matchesSection은 확보한 진술을 화면 분류에 맞게 골라냅니다. 진술을 새로 획득하는 판정은 FastAPI가 합니다.

## 읽는 기준

아래 코드는 현재 소스의 선언에서 본문을 제외한 것입니다. 입력과 반환 설명은 해당 함수의 JSDoc을 기준으로 정리했습니다. `Props`는 각 화면 파일에 정의된 입력 타입이며, 타입의 전체 필드는 소스 링크에서 확인합니다.

## app/game/testimony/sections.ts

[소스 열기](../../../app/game/testimony/sections.ts)

### matchesSection

```ts
export function matchesSection(item: AcquiredStatement, section: string)
```

역할: 선택한 증언 분류에 해당하는지 확인한다.

입력:

- `item`: 확인할 자료 또는 진술.
- `section`: 선택한 증언 분류.

반환: 진술이 선택한 분류에 속하면 true.
