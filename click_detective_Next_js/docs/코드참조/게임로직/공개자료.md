# 공개 사건 자료와 타입

초기 카탈로그 응답을 받은 뒤 installCatalog와 installLibrary로 화면 표시 자료를 준비합니다.

## 읽는 기준

아래 코드는 현재 소스의 선언에서 본문을 제외한 것입니다. 입력과 반환 설명은 해당 함수의 JSDoc을 기준으로 정리했습니다. `Props`는 각 화면 파일에 정의된 입력 타입이며, 타입의 전체 필드는 소스 링크에서 확인합니다.

## app/game/catalog/case-library.ts

[소스 열기](../../../app/game/catalog/case-library.ts)

이 파일의 타입: `LibraryCase`.

### installLibrary

```ts
export function installLibrary(cases: LibraryCase[])
```

역할: 사건 기록실에 표시할 카드 목록을 보관한다.

입력:

- `cases`: 서버에서 받은 사건 카드 목록.

반환: 없음. 사건 선택 자료를 갱신한다.

## app/game/catalog/catalog.ts

[소스 열기](../../../app/game/catalog/catalog.ts)

### installCatalog

```ts
export function installCatalog(data: PublicCatalog)
```

역할: 브라우저가 초기 카탈로그를 받은 후 원본 화면의 읽기 전용 표시 자료를 준비합니다.

입력:

- `data`: 서버에서 받은 공개 자료.

반환: 없음. 카탈로그 표시 자료를 갱신한다.

## app/game/catalog/types.ts

[소스 열기](../../../app/game/catalog/types.ts)

이 파일의 타입: `CaseInfo`, `Choice`, `EvidenceRecord`, `Person`, `PublicCatalog`.

화면에서 사용하는 타입·상수 또는 표시 자료를 정의합니다. 함수 실행 본문은 이 파일에 없습니다.
