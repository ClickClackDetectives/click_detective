# 추론 출처의 표시와 식별자

자료 종류·번호·제목·근거 설명을 화면에 표시하기 위한 함수입니다. 조합의 정답 판정은 서버에서 수행합니다.

## 읽는 기준

아래 코드는 현재 소스의 선언에서 본문을 제외한 것입니다. 입력과 반환 설명은 해당 함수의 JSDoc을 기준으로 정리했습니다. `Props`는 각 화면 파일에 정의된 입력 타입이며, 타입의 전체 필드는 소스 링크에서 확인합니다.

## app/game/inference/sources.ts

[소스 열기](../../../app/game/inference/sources.ts)

이 파일의 타입: `SourceCategory`.

### describeSource

```ts
export function describeSource(state: GameState, ref: SourceRef)
```

역할: 자료 참조를 화면용 번호·제목·보충 설명으로 변환한다.

입력:

- `state`: 서버에서 확인한 현재 수사 상태.
- `ref`: 자료 종류와 ID가 담긴 출처.

반환: 자료 종류·번호·제목·설명이 담긴 표시용 출처.

### getInferenceSources

```ts
export function getInferenceSources(state: GameState)
```

역할: 실제 출처 후보도 서버에서 받은 목록을 사용합니다.

입력:

- `state`: 서버에서 확인한 현재 수사 상태.

반환: 현재 수사에서 확보한 연결 후보 목록.

### getInferenceBasisLabel

```ts
export function getInferenceBasisLabel(state: GameState, sources: SourceRef[])
```

역할: 도출 문서의 근거 종류 이름은 서버가 계산합니다.

입력:

- `state`: 서버에서 확인한 현재 수사 상태.
- `sources`: 추론을 구성한 출처 목록.

반환: 서버가 알려준 추론 근거 설명. 해당 설명이 없으면 기본 문구.

### sourceKey

```ts
export function sourceKey(ref: SourceRef)
```

역할: 자료 종류와 ID를 합쳐 목록의 식별자를 만든다.

입력:

- `ref`: 자료 종류와 ID가 담긴 출처.

반환: 자료 종류와 ID를 합친 문자열.
