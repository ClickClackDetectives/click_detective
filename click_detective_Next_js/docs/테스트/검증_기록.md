# 검증 기록과 범위

이 페이지는 마지막 코드 분리 작업에서 실행한 결과를 보관합니다. 이번 문서 재구성에서는 문서 링크·함수 선언·파일 경로를 별도로 확인하며, 게임 서버·모델 검사를 다시 실행하지 않습니다.

## 마지막 코드 변경 후 확인한 결과

| 확인 항목 | 결과 |
| --- | --- |
| `npm test` | 검사 파일 5개 통과 |

HTTP 보고서 작성 시각(UTC): `2026-11-16T06:26:12.828Z`. 브라우저 보고서 작성 시각(UTC): `2026-11-16T06:25:59.850Z`.

## 실제로 검사한 환경

- 명시적인 `fixture` 모드의 FastAPI와 빌드된 Next.js를 연결했습니다.
- 별도 임시 SQLite를 사용하고 검사에서 만든 서버를 종료했습니다.
- 리팩토링 이전 소스의 별도 사본과 같은 수사 상태·화면 폭·로컬 글꼴 조건으로 비교했습니다.
- 외부 웹폰트 요청을 차단하고 양쪽에서 이미지와 글꼴 준비를 기다렸습니다.

새 수사·오프닝, 자료 열람·문서 팝업·심문 첨부, 실제 심문 요청·응답, 메모 자동 저장, 새로고침 복원을 조작했습니다.

## 해석할 때 구분할 점

현재 결과는 fixture 환경의 연결·게임·화면 검사입니다. `actualLlmTested`는 `false`이며 실제 GPU·LLM 생성 품질을 검증한 결과는 아닙니다. 화면 18개 비교는 지정한 화면·상태·글꼴에서의 결과이며 모든 브라우저·기기 조합을 의미하지 않습니다.
