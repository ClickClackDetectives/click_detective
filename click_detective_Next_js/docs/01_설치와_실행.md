# 설치와 실행

이 프로젝트는 화면 서버 하나만 켜서 완성되는 구조가 아닙니다. **FastAPI를 먼저 준비하고 Next.js를 실행**해야 합니다. 브라우저는 Next.js 주소로 접속합니다.

## 1. 폴더와 실행 도구 확인

```text
~/reverse/
  share_project/             원본 UI 및 비교 기준
  click_detective/           FastAPI·사건 데이터·DB·모델 설정
    .cd_venv/                백엔드 Python 가상환경
    .env                     백엔드 설정
  click_detective_nextjs/    실제로 연결해 사용하는 Next.js
    .env.local               Next.js 서버 설정
```

프런트엔드 `package.json`의 Node.js 요구사항은 **22.18.0 이상**입니다. 다음 명령은 버전 확인만 합니다.

```bash
node --version
npm --version
~/reverse/click_detective/.cd_venv/bin/python --version
```

`.cd_venv`는 백엔드용입니다. Next.js는 Python 가상환경이 아니라 Node.js와 npm을 사용합니다. 가상환경이 없거나 백엔드 의존성이 준비되지 않았다면 먼저 [백엔드 설치 안내](../../click_detective/docs/02_설치_설정_실행.md)를 따르세요.

## 2. 두 환경변수 파일의 차이

| 파일                                | 읽는 프로그램  | 주된 설정                                       |
| ----------------------------------- | -------------- | ----------------------------------------------- |
| `click_detective/.env`              | Python FastAPI | `CLICK_API_KEY`, 생성 모드, 모델·어댑터·DB 경로 |
| `click_detective_nextjs/.env.local` | Next.js 서버   | FastAPI 주소·서버 간 API 키·응답 대기시간       |

이 두 파일은 이름과 역할이 다릅니다. Next.js는 옆 폴더의 `.env`에서 API 키를 자동으로 가져오지 않습니다. 현재 `.env.local`은 생성 당시 백엔드 키에 맞춰 준비되어 있지만, **백엔드 키를 나중에 바꾸면 Next.js 설정도 함께 바꿔야 합니다.**

Next.js 설정 예시는 다음과 같습니다. `여기에_같은_키_입력`은 설명용 문자열이므로 실제 실행 시에는 백엔드의 `CLICK_API_KEY`와 같은 값을 넣으세요.

```dotenv
CLICK_DETECTIVE_API_URL=http://127.0.0.1:8000
CLICK_DETECTIVE_API_KEY=여기에_같은_키_입력
CLICK_DETECTIVE_TIMEOUT_MS=120000
```

| 이름                         | 의미                                 | 현재 코드 동작                                             |
| ---------------------------- | ------------------------------------ | ---------------------------------------------------------- |
| `CLICK_DETECTIVE_API_URL`    | Next.js 서버에서 접근할 FastAPI 주소 | HTTP 또는 HTTPS 주소 사용, URL 안의 사용자명·비밀번호 거절 |
| `CLICK_DETECTIVE_API_KEY`    | 서버 간 인증 키                      | FastAPI의 `CLICK_API_KEY`와 일치해야 함                    |
| `CLICK_DETECTIVE_TIMEOUT_MS` | FastAPI 응답 대기시간                | 기본 120,000ms, 1,000~600,000ms 범위로 제한                |

120,000ms는 120초입니다. 이 값은 Next.js 중계의 대기시간이고, 백엔드 `CLICK_TIMEOUT_SECONDS`와는 별도 설정입니다. 값을 늘려도 모델 검증 실패나 GPU 메모리 부족이 해결되지는 않습니다.

`.env.local`이 없는 새 환경에서는 아래 명령으로 예제 파일을 복사한 뒤 편집하세요. **이미 설정한 파일이 있다면 복사해 덮어쓰지 않습니다.**

```bash
cd ~/reverse/click_detective_nextjs
cp .env.local.example .env.local
```

키에 `NEXT_PUBLIC_` 접두사를 붙이지 마세요. 이 프로젝트의 키는 서버에서만 사용합니다. 실제 키를 문서·스크린샷·공개 저장소에 넣지 않습니다.

환경변수를 수정한 다음에는 해당 서버를 재시작하세요. 운영체제에서 이미 지정한 같은 이름의 환경변수도 영향을 줄 수 있으므로, 파일을 바꿨는데 값이 유지되면 터미널·서비스 실행 설정도 확인합니다.

## 3. 실행 모드 선택

### 실제 Qwen을 사용하는 경우

FastAPI가 `local` 모드로 시작되어야 합니다. 모델 파일, 기존에 학습한 어댑터, GPU 관련 의존성이 백엔드에 준비되어 있어야 합니다. 양자화와 어댑터 적용은 백엔드가 담당합니다. Next.js가 모델을 다운로드하거나 학습하지 않습니다.

모델은 서버 시작 과정에서 로딩됩니다. FastAPI 시작 완료 전에 화면을 열면 연결 오류가 날 수 있습니다.

### GPU 없이 연결을 확인하는 경우

`fixture` 모드를 명시적으로 사용할 수 있습니다. 이는 실제 LLM 생성이 아니며, UI·데이터 흐름·저장·게임 API 연결을 확인하기 위한 모드입니다.

```bash
cd ~/reverse/click_detective
CLICK_GENERATION_MODE=fixture \
CLICK_DATABASE_PATH=.data/nextjs-dev-fixture.sqlite3 \
.cd_venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

위 예시는 개발용 DB를 따로 지정합니다. 기존 운영 DB를 비우는 명령이 아닙니다. 이미 8000 포트에서 서버가 실행 중이라면 같은 포트에 두 번째 서버를 띄우지 않습니다.

## 4. 터미널 A에서 FastAPI 실행

실제 모델 모드에서는 백엔드 `.env` 설정을 확인한 뒤 실행합니다.

```bash
cd ~/reverse/click_detective
.cd_venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

`Application startup complete` 등 시작 완료 로그를 확인합니다. 별도 터미널에서 다음과 같이 준비 상태를 조회할 수 있습니다.

```bash
curl http://127.0.0.1:8000/healthz
```

기대하는 응답은 `{"status":"ok"}`입니다. 이 응답은 서버 준비 여부를 뜻하며 대사 품질 점수나 양자화 검증 결과는 아닙니다.

## 5. 터미널 B에서 Next.js 실행

```bash
cd ~/reverse/click_detective_nextjs
npm ci
npm run dev
```

`npm ci`는 잠금 파일에 맞춰 의존성을 설치합니다. 이미 설치되어 있고 의존성 변경이 없다면 매번 반복할 필요는 없습니다.

브라우저에서 **http://localhost:3000** 으로 접속합니다. 사건 카탈로그를 받은 뒤 원본 홈 화면이 나타납니다. 처음에는 ‘첫 번째 사건 시작하기’, 진행 중인 수사가 복원되면 ‘수사 이어하기’가 표시됩니다.

첫 확인 순서는 홈 → 사건 시작 → 오프닝 닫기 → 증거 보관실 → 자료 열람 → 용의자 심문입니다. 자세한 조작은 [화면 사용법](03_화면_사용법.md)에 있습니다.

## 6. 빌드한 결과로 실행

```bash
cd ~/reverse/click_detective_nextjs
npm run build
npm run start
```

`build`는 배포용 결과물을 만들고 `start`는 그 결과물을 실행합니다. 수정한 코드를 `start`로 확인하려면 다시 빌드해야 합니다. 개발 서버 `dev`와 운영 형태의 `start`를 같은 포트에서 동시에 실행하지 않습니다.

포트를 바꾸려면 Next.js 옵션을 전달할 수 있습니다.

```bash
npm run dev -- --port 3001
```

브라우저도 바꾼 포트로 접속해야 합니다. Next.js 포트를 바꾸는 것과 FastAPI 주소를 바꾸는 것은 별개입니다.

## 7. 다른 컴퓨터나 프록시 환경

`127.0.0.1`은 명령을 실행하는 서버 자신입니다. Next.js와 FastAPI가 서로 다른 컨테이너·서버에 있으면 Next.js에서 접근 가능한 백엔드 주소를 지정해야 합니다.

운영 환경에서는 HTTPS를 사용하고 프록시의 Host·프로토콜 전달을 맞춥니다. 변경 요청은 브라우저 Origin과 요청 Host·프로토콜로 구성한 출처를 비교합니다. 이 값이 어긋나면 정상 버튼 클릭도 403이 될 수 있습니다.

원본 CSS의 외부 폰트 선언은 유지되어 있습니다. 폰트 서버에 접근할 수 없는 환경에서는 대체 폰트로 표시될 수 있습니다. 해당 환경 차이와 UI 구현 변경을 구분해서 확인하세요.

## 대사가 끊기지 않도록 하는 기본 설정

백엔드 `.env`의 `CLICK_FALLBACK_ON_ERROR=true`가 기본 플레이 정책입니다. 모델 실패는 승인 원문 fallback으로 복구하고 정보가 없는 질문은 중립 fixed 응답을 돌려줍니다. 설정 변경은 FastAPI를 재시작해야 적용됩니다. Next.js가 임의 대사를 만드는 기능은 아닙니다. [상세 정책](../../click_detective/docs/12_질문_응답과_복구_정책.md)
