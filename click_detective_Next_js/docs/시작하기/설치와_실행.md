# 설치와 실행

설치와 환경 설정만 설명합니다. 실행 중 데이터 흐름은 [동작 순서](../구조/동작_순서.md), 검사 명령은 [검사 안내](../테스트/검사와_오류해결.md)에서 확인하세요. 명령은 저장소 루트에서 시작하는 Linux/Bash 기준입니다. Node.js 22.18.0 이상, npm, Python 3.11 이상이 필요합니다.

## 1. FastAPI 준비

백엔드 설치·환경변수는 [FastAPI 실행 안내](../../../click_detective_FastAPI/README.md)를 따릅니다. 새 환경을 만든다면 다음과 같이 실행합니다.

```bash
cd click_detective_FastAPI
python3 -m venv .venv
source .venv/bin/activate
pip install -e '.[dev]'
cp .env.example .env
```

기존 `.env`가 있다면 복사하지 말고 설정을 확인하세요. `.env`의 `CLICK_API_KEY`를 정하고 별도 터미널에서 실행합니다.

```bash
CLICK_GENERATION_MODE=fixture python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --workers 1
```

`http://127.0.0.1:8000/healthz`에서 `{"status":"ok"}`를 확인합니다. `fixture`는 GPU와 실제 모델 없이 게임과 연결을 확인하는 모드입니다. 실제 모델은 백엔드 문서에 따라 `local` 모드를 준비해야 합니다.

## 2. Next.js 준비

별도 터미널에서 저장소 루트 기준으로 실행합니다.

```bash
cd click_detective_Next_js
npm ci
cp .env.local.example .env.local
```

기존 `.env.local`이 있으면 덮어쓰지 않습니다. 다음 값을 설정합니다.

```dotenv
CLICK_DETECTIVE_API_URL=http://127.0.0.1:8000
CLICK_DETECTIVE_API_KEY=백엔드_CLICK_API_KEY와_같은_값
CLICK_DETECTIVE_TIMEOUT_MS=120000
```

| 변수 | 의미 |
| --- | --- |
| `CLICK_DETECTIVE_API_URL` | Next.js 서버에서 접근할 FastAPI 주소 |
| `CLICK_DETECTIVE_API_KEY` | 백엔드 `.env`의 `CLICK_API_KEY`와 같은 값 |
| `CLICK_DETECTIVE_TIMEOUT_MS` | 응답을 기다릴 시간(ms). 기본 120000, 1000~600000 범위 |

Next.js는 백엔드 `.env`를 자동으로 읽지 않습니다. 키는 `NEXT_PUBLIC_` 변수에 넣지 않습니다. 두 서버가 다른 컴퓨터·컨테이너에 있다면 서버 사이에서 접근할 수 있는 주소를 사용합니다. 설정 변경 후 Next.js를 재시작합니다.

## 3. 개발 및 배포용 실행

```bash
npm run dev
```

브라우저에서 `http://localhost:3000`에 접속합니다. 다른 포트는 `npm run dev -- --port 3001`입니다.

개발 서버를 종료하고 배포용 실행을 확인하려면 다음 명령을 사용합니다.

```bash
npm run build
npm run start
```

변경한 코드는 다시 빌드해야 반영됩니다. 빌드 산출물 `.next`, 비밀 설정 `.env.local`, 검사 보고서 `.reports`는 소스에 포함하지 않습니다.
